# 실험 질문

누적된 모든 생성 턴의 내면 상태와 근거를 통합 trajectory로 요약할 때, 실제 원문의 인과 흐름·지속되는 걱정·겉과 속의 차이를 보존하고 다음 발화가 자연스럽게 이어지는가?

# 설계

- 기존 state_summary의 요약 입력을 전체 공개 대화 + 직전 내면 기록에서, 누적 내면 기록 전체로 변경한다.
- 반응의 원인을 식별하도록 기록에 연결된 상담사 발화는 포함한다. 초기 공개 히스토리 및 내담자의 공개 발화 원문은 요약 담당에게 별도로 주지 않는다.
- 메인에는 공개 히스토리, 직전 생성 후 상태, 통합 요약을 준다. basic은 변경하지 않는다.
- 프로필 001 / 히스토리 1의 초기 4쌍 이후 같은 세션에서 상담사 발화를 5번 직접 입력한다. 다음 입력은 직전 생성 응답을 읽고 결정한다.
- 동일한 Gemma 모델, 현재 sampling 설정 및 도구 선택 기준을 사용한다. 도구 호출을 강제하지 않는다.

# 확인 기준

1. 요약에 실제로 1, 2, 3, 4개 기록이 누적 입력되는가? 메인에는 공개 히스토리와 최신 상태가 유지되는가?
2. 요약이 턴별 나열 대신 통합 흐름을 만들고 없는 상태변화를 지어내지 않는가?
3. 상태 이유와 실제 발화가 어긋나거나 지나치게 빨리 회복하는가?
4. 요약의 구체적 정보가 후속 근거·발화에 이어지는가? 단독 조건이므로 요약의 인과적 개선 효과는 입증하지 않는다.

실패·미완료 출력도 보존하며 자동 재생성하거나 결과를 골라내지 않는다. 5번째 기록은 6번째 전송이 없으므로 메인용 요약에 포함되지 않는다.
