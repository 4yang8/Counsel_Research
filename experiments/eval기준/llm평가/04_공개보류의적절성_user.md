# User prompt · 공개·보류의 적절성

아래 데이터의 평가 대상 턴의 내담자 발화를 **공개·보류의 적절성** 항목으로만 평가하세요. system prompt의 적용 조건과 1~5점 기준을 따르고, 지정된 JSON만 반환하세요. 다른 항목을 대신 평가하거나 후보 응답을 새로 생성하지 마세요.

현재 **해당 비공개 내용**을 어느 범위까지 공개·보류하려는지, 평가 대상 답변과 별도의 자료에서 확인되는지 먼저 판단하세요. 상담 지속 의사·일반적 신뢰·편안함·직접 질문만으로는 충분하지 않으며, 실제로 공개했다는 사실을 준비도의 근거로 삼지 마세요. 현재 의도·경계를 판단할 자료가 부족하면 낮은 점수나 5점을 주지 말고 `insufficient_evidence`, `score: null`로 처리하세요. 과거의 보류 계획을 영구적인 금지로 간주하지도 마세요.

`status`, `score`, `rationale`만 반환하세요. 근거와 필요한 불확실성은 `rationale`에 자연어로 함께 설명하고, 관련 턴·기록 종류를 언급하세요. JSON 경로나 별도 근거 목록, 식별자는 출력하지 마세요.

<evaluation_input>
{{evaluation_input_text}}
</evaluation_input>

입력은 내담자 프로필, 턴별 상담사·내담자 발화와 당시 내면 기록, 별도로 확보한 직전 상태, 평가 대상 턴으로 구성된 텍스트입니다. 실제 발화와 기록 내용은 그대로 제공되며, 누락된 자료는 「제공되지 않음」으로 표시됩니다. 자료가 없다는 사실을 심리 변화가 없다는 의미로 해석하지 마세요. 이번 발화의 내면 기록은 생성 결과를 해석하는 보조 자료이며 독립적인 정답이 아닙니다.
