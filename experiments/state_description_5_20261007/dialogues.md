## 1. 원래 설명

### Function description

특정 상태값이 언제, 어떤 출처와 근거로 설정되었는지 기록을 조회합니다. 현재 상태와 최근 내담자 발화가 상반되어 보이거나, 겉으로 한 말과 내부 상태의 관계를 판단할 근거가 부족할 때 사용합니다. 시점·근거가 이미 명확하면 조회할 필요가 없습니다. 실제 저장된 기록만 제공하며 기록이 없을 수 있습니다. 상태를 변경하거나 이번 감정을 대신 결정하지 않습니다.

### 생성 응답

- **느낌**: 이해받음
- **판단 이유**: 상담자가 직전 발화에서 내담자가 느낀 '준비 부족에 대한 인정'과 '평가에 대한 걱정'을 모두 짚어주며 공감했고, 내담자 또한 "선생님이 제 마음을 이해해주시는 것 같아요"라고 반응하며 신뢰가 형성된 상태입니다(dialogue). 이번 발화에서도 내담자의 감정을 먼저 수용("그렇게 느끼셨군요")한 뒤, 내담자가 계속 되짚고 있던 '답이 막혔던 순간'에 대해 구체적으로 묻고 있어, 자신의 괴로운 지점을 함께 탐색하려 한다는 느낌을 받습니다.
- **내담자 발화**: "음... 일단은 정말 당황스러웠어요. 교수님이 질문하신 순간에 머릿속이 하얘지면서 '아, 이걸 당연히 설명할 수 있어야 하는데 왜 말이 안 나오지?'라는 생각이 제일 먼저 들었던 것 같아요. 제가 너무 한심하게 느껴졌어요."

## 2. 역할과 입출력 명시

### Function description

당신은 내담자의 반응을 작성하고 있습니다. 입력에 있는 상태 수준과 대화만으로 그 상태의 배경을 알 수 없을 때, 이 내담자의 상태 설정 기록을 조회하는 도구입니다. state에 trust(상담자 신뢰), disclosure(자기개방 의향), change_confidence(변화 자신감) 중 하나를 지정하세요. 현재 입력된 수준과 기록된 설정 시점·출처·근거·변화 이력을 반환합니다. 확인한 기록을 상담자 발화를 어떻게 받아들일지 판단하는 데 참고하세요. 기록이 없을 수 있으며 상태를 변경하지 않습니다.

### 생성 응답

- **느낌**: 이해받음
- **판단 이유**: 상담자가 이전 턴에서 "제가 너무 빨리 안심시키려 했네요"라며 자신의 실수를 인정하고 내담자의 준비 부족에 대한 마음을 수용해주었습니다. 이에 내담자가 "선생님이 제 마음을 이해해주시는 것 같아요"라고 반응하며 신뢰가 형성된 상태(dialogue)입니다. 이번 발화에서도 "그렇게 느끼셨군요"라며 공감을 먼저 표현하고, 내담자가 계속해서 곱씹고 있던 '답이 막혔던 순간'에 대해 구체적으로 이야기할 기회를 주었으므로, 자신의 괴로움과 상황을 충분히 알아준다고 느낍니다.
- **실제 발화**: "음... 일단은 정말 당황스러웠어요. 교수님이 질문하신 순간에 머릿속이 하얘지면서 '아, 이걸 당연히 설명할 수 있어야 하는데 왜 말이 안 나오지?'라는 생각이 제일 먼저 들었던 것 같아요. 제가 너무 한심하게 느껴졌어요."

## 3. 판단에 필요한 정보 명시

### Function description

상담자 발화에 대한 내담자의 반응을 정하기 전에, 상태값과 대화 히스토리의 관계를 확인하는 도구입니다. 현재 입력된 상태가 최근 대화를 반영한 것인지, 어떤 근거로 정해졌는지 불명확하면 해당 상태를 조회하세요. 반환되는 설정 시점과 근거를 이용해 과거의 말과 현재 상태를 구분하세요. 이미 근거가 주어졌다면 다시 조회하지 않아도 됩니다. 기록이 없으면 원인을 알 수 없다는 뜻이며, 이 도구는 상태나 감정을 대신 결정하지 않습니다.

### 생성 응답

- **느낌**: 이해받음
- **판단 이유**: 상담자가 직전 발화에서 내담자가 느낀 '준비 부족에 대한 인정'과 '평가에 대한 걱정'을 모두 수용해주었고, 이번 발화에서도 "그렇게 느끼셨군요"라며 내담자의 정서를 먼저 반영해주었습니다. 내담자는 이미 "선생님이 제 마음을 이해해주시는 것 같아요"라고 말하며 신뢰를 보이기 시작한 상태(dialogue 마지막 턴)이므로, 자신의 구체적인 생각(사건 당시의 내면 경험)을 묻는 상담자의 요청을 자연스러운 공감과 탐색의 과정으로 받아들였습니다.
- **내담자 발화**: "음... 일단은 너무 당황스러웠어요. 교수님이 질문하신 순간에 '아, 이걸 당연히 말할 수 있어야 하는데 왜 생각이 안 나지?' 하는 생각부터 들더라고요. 그러면서 동시에 주변에 다른 사람들이 같이 있었다는 게 갑자기 의식돼서 더 머릿속이 하얘졌던 것 같아요."

## 4. 관찰 가능한 호출 조건

### Function description

최근 내담자 발화가 제공된 상태 수준과 다른 방향의 신호를 보일 때 사용하는 상태 근거 조회 도구입니다. 낮은 신뢰와 신뢰 표현, 낮은 자기개방 의향과 상세히 말하려는 표현, 낮은 변화 자신감과 할 수 있다는 표현 등이 함께 주어지면, 반응을 작성하기 전에 해당 상태를 조회하세요. state로 상태 항목을 선택하고 reason에 두 정보의 어떤 관계를 확인하려는지 적으세요. 설정 시점·출처·근거·기록된 변화 이력을 반환하므로, 시점 차이인지 같은 시점에 양립하는 반응인지 판단하는 데 참고할 수 있습니다. 기록이 없으면 그 관계는 확인되지 않은 것입니다. 상태를 자동 변경하지 않습니다.

### 생성 응답

- **느낌**: 이해받음
- **판단 이유**: 상담자가 직전 발화에서 "너무 빨리 안심시키려 했다"며 자신의 실수를 인정하고 내담자의 마음(준비 부족에 대한 인정과 교수님 평가에 대한 걱정)을 정확히 짚어주었습니다. 이에 내담자가 "마음을 이해해주시는 것 같다"며 신뢰를 보인 상태(dialogue)에서, 상담자가 다시 한번 내담자의 감정을 수용("그렇게 느끼셨군요")하고 구체적인 내면의 생각에 관심을 보여주었기에 '이해받음'을 느꼈습니다.
- **실제 발화**: 음... 그 순간에는 정말 머릿속이 하얘졌어요. '아, 이걸 왜 생각 못 했지?'라는 생각과 동시에, 저를 쳐다보시는 교수님 표정이 보였거든요. 그때 갑자기 제가 너무 한심하게 느껴졌고, 여기서 제대로 답 못 하면 정말 무능하게 보일 것 같다는 생각에 당황스러웠어요.

## 5. 해석 전 확인할 정보의 경계

### Function description

이 도구는 입력된 상태 수준이 어떤 시점과 근거에서 나온 값인지 저장된 기록으로 확인합니다. 최근 내담자 발화를 보고 제공된 상태보다 신뢰·공개 의향·자신감이 높아졌거나 낮아졌다고 해석하려면, 먼저 해당 상태를 조회하세요. 발화와 상태가 다른 이유를 시간 변화나 숨은 마음으로 설명하려는 경우에도, 기록에 그 근거가 있는지 확인하세요. state에는 trust, disclosure, change_confidence 중 확인할 항목을, reason에는 확인하려는 관계를 적습니다. 반환된 시점·출처·근거·이력을 참고하여 상담자 발화에 대한 느낌과 내담자 발화를 작성하세요. 확인되지 않은 변화 이유를 도구가 밝혀준 것처럼 말하지 마세요. 이미 필요한 기록이 있으면 생략하며, 이 도구는 상태를 갱신하지 않습니다.

### 생성 응답

- **느낌**: 이해받음
- **판단 이유**: 상담자가 직전 발화에서 "너무 빨리 안심시키려 했다"며 자신의 실수를 인정하고 내담자의 복합적인 마음(준비 부족에 대한 인정 + 평가에 대한 걱정)을 정확히 짚어주었습니다. 이에 내담자가 "마음을 이해해주시는 것 같다"며 신뢰감을 보인 상태(dialogue)에서, 상담자가 다시 한번 내담자의 감정을 수용("그렇게 느끼셨군요")하고 구체적인 경험으로 부드럽게 안내하고 있어 이해받고 있다는 느낌을 유지하게 됩니다.
- **내담자 발화**: "음... 우선은 정말 당황스러웠어요. 교수님이 질문하셨을 때 머릿속이 갑자기 하얘지면서, '아, 당연히 대답할 수 있어야 하는 건데 왜 말이 안 나오지?' 하는 생각부터 들더라고요. 그 짧은 침묵이 저한테는 너무 길게 느껴졌어요."
