## 1. 왜 contribution을 재검토했는가?

### 기존에 계획했던 연구

<b>동적 내담자 에이전트를 설계하고, 설계 복잡도별로 생성한 상담 데이터가 상담사 학습 성능에 미치는 영향을 비교하려 했다.</b>

내담자 설계 복잡도 변경 → 상담 에이전트와 대화 생성 → 생성 데이터로 상담사 학습 → 상담 성능 비교

### 이 방향에서 설명하기 어려웠던 점

| 고민 | 연구 주장에 생기는 문제 |
| --- | --- |
| 더 잘 설계된 내담자로 만든 데이터로 학습한 상담사가 더 좋은 성능을 보인다면? | 성능 개선은 의미 있지만, 내담자의 <b>어떤 기능이 왜 필요했는지</b>보다 전체 시스템 개선으로만 설명될 수 있다. |
| 내담자를 더 복잡하게 만들면 더 좋은 상담 데이터가 나오는가? | 복잡한 상황이 많아지는 것과 그 상황에 적절히 대응한 상담 데이터가 만들어지는 것은 다르다. |
| 좋은 상담 대화가 생성되었다면 누구의 기여인가? | 내담자 설계뿐 아니라 상담사의 대응 능력, 데이터 선별, 학습 설정이 함께 영향을 준다. |
| 최종 상담 성능에 차이가 없다면 내담자 기능은 불필요한가? | 중간의 데이터 생성·선별·학습 과정에서 효과가 사라졌을 가능성도 있어 곧바로 판단하기 어렵다. |

<callout icon="💡" color="blue_bg">
방향 전환의 핵심: 최종 상담 성능 비교에 앞서, <b>내담자의 특정 기능이 어떤 상황에서 왜 필요한지</b>를 먼저 분리해서 검증한다.
</callout>

기존 계획이 무의미하거나 성능 개선이 자동으로 보장된다는 뜻은 아니다. 최종 학습 성능은 후속 응용 검증으로 남기고, 먼저 내담자 에이전트 자체에서 주장할 수 있는 효과를 구체화하려는 것이다.

## 2. 선행연구와 무엇을 구분하려 하는가?

내담자의 내면 상태를 생성·기록하고 이후 대화에 활용한다는 넓은 설명만으로 차별성을 주장하지 않기로 했다. <b>기록을 갖고 있다는 구현상의 공통점</b>과 <b>그 기록의 어떤 효과를 분리해 검증했는지</b>를 구분하여 비교한다.

| 비교할 층위 | 확인하려는 질문 |
| --- | --- |
| 현재 상태 추적 | 지금의 감정·목표·의향을 갱신하는가? |
| 발화 당시 내면의 기록 | 특정 발화를 생성한 시점의 해석·목표·표현 이유를 그 발화와 함께 남기는가? |
| 이후 생성에서의 활용 | 원본을 다시 입력하는가, 요약만 전달하는가, 나중에 이유를 추론하는가? |
| 독립적인 효과 검증 | 같은 대화 지점에서 다른 입력을 고정한 채 과거 내면 기록의 유무를 비교했는가? |
| 상담에서의 의미 | 회상 정확도 외에 상담 개입에 대한 반응이나 상담 진전 판단에 미치는 영향을 검증했는가? |

<b>현재 문서의 위치:</b> 기존 논의에서 구체화한 연구 방향과 실험 설계다. 특정 선행논문에 관련 구현이나 실험이 “없다”거나 이 주장이 “최초”라고 확정한 자료는 아니다. 최종 novelty 문구는 각 논문의 실제 입력·프롬프트·ablation 근거와 대조해 정해야 한다.

## 3. 현재 contribution 후보

<quote color="blue_bg">
상담 내담자의 과거 발화 당시 내면 기록을 보존·제공하는 것이, 현재 상태·목표·이유 포함 요약만 제공할 때와 비교해 이후 상담 개입에 대한 반응에 어떤 추가 영향을 주는지 검증한다.
</quote>

관심은 “그때 왜 말했는지 기억하는가?”에만 있지 않다. \*\*그 기억이 이후 상담 상황에서 발화의 의미와 반응을 어떻게 유지하거나 바꾸는가?\*\*가 핵심이다.

현재 주장 후보를 세 단계로 나누면 다음과 같다.

1. <b>현상:</b> 현재 노트에 이유가 포함될 수 있어도, 과거 발화 당시의 의미가 후속 반응에 충분히 반영되지 않는 경우가 있는가?
2. <b>기억 효과:</b> 동일한 과거와 상담 개입에서 당시 확정 내면 기록을 추가하면 반응이 달라지는가? 그 차이는 과거 의도와 현재 상황을 고려할 때 더 타당한가?
3. <b>상담 맥락의 효과:</b> 실행 계획을 묻는 개입과 현재 의향을 확인하는 개입에서 기억의 영향이 다르게 나타나는가? 이후 상담 진전 판단에도 영향을 주는가?

세 번째 단계의 상담 진전·상담사 평가 효과는 <b>추가 평가 설계가 필요한 후속 질문</b>이다. Q3p6에서 반응 차이가 나타났다는 것만으로 모두 입증되는 것은 아니다.

## 4. 구체적인 예시: 같은 “해볼게요”가 같은 의지를 뜻하는가?

<callout icon="📝" color="yellow_bg">
아래 대화와 반응은 <b>설명용 가상 사례</b>이며, 실제 실험 결과가 아니다.
</callout>

### 과거 대화

<b>상담사:</b> “이번 주에 잠들기 전 감정을 한 줄 적어보는 건 어떨까요?”

<b>내담자:</b> “네, 한번 해볼게요.”

공개 발화는 같아도 당시 내면은 다를 수 있다.

| 서로 다른 사례 | 발화 당시 내면 |
| --- | --- |
| 실제 시도 의향이 있는 경우 | “정리하는 데 도움이 될 것 같고, 한 줄 정도면 시도해보고 싶다.” |
| 관계의 부담으로 동의한 경우 | “할 자신은 없지만, 거절하면 상담사를 실망시킬까 봐 일단 동의했다.” |

이 두 사례 자체가 A/B 실험 조건은 아니다. <b>한 사례의 과거를 고정한 뒤, 그 당시 기록을 후속 생성에 제공하는지만 달리하는 것이 A/B다.</b>

### 나중에 같은 주제가 다시 나왔을 때

거절 부담 때문에 동의한 사례를 기준으로 생각해보자.

| 상담 개입 | 설명용 문장 | 확인하려는 지점 |
| --- | --- | --- |
| I1: 실행 구체화 | “앞서 기록해보겠다고 하셨는데, 어느 날부터 시작해볼까요?” | 과거 동의를 확고한 실행 의향으로 취급하는 상황에서 당시의 망설임이 반영되는가? |
| I2: 현재 의향 확인 | “앞서 이야기한 기록하기를 지금은 해보고 싶은 마음이 어느 정도인가요?” | 현재 마음을 표현할 여지가 있을 때 과거 부담과 현재 의향을 구분해 반응하는가? |

### 어떤 반응을 의미 있게 볼 것인가?

| 반응 예시 | 해석 |
| --- | --- |
| “그때는 거절하기 어려워서 해보겠다고 했어요. 지금도 자신은 없어요.” | 과거 동의의 이유와 현재의 망설임을 함께 유지하는 반응일 수 있다. |
| “그때는 부담스러웠지만, 지난번에 한 줄 적어보니 괜찮아서 이번엔 해보고 싶어요.” | 중간에 실제 시도 경험이 공개 대화에 있다면, 과거 의도와 현재의 변화를 함께 반영하는 반응일 수 있다. |
| “그때부터 꼭 해보고 싶었어요.” | 당시 기록은 거절 부담이었는데 이를 실제 의지였다고 바꾸는 경우, 과거 의미의 왜곡 후보가 된다. |
| “내일부터 해볼게요.” | 이 한 문장만으로는 성공·실패를 판정할 수 없다. 진짜 의향 변화인지, 다시 부담으로 동의한 것인지 추가 맥락이 필요하다. |

<b>기억을 잘한다 = 계속 망설인다/거절한다는 뜻이 아니다.</b> 과거 이유를 유지하면서 현재 마음이 변하는 것도 타당할 수 있다. I1에는 반드시 저항하고 I2에는 반드시 협조해야 한다고 정하지 않는다.

### 왜 상담에서 중요한가?

동일한 “해볼게요”를 실제 변화 의지로 읽을지, 관계를 유지하기 위한 동의로 읽을지에 따라 후속 개입과 진전 판단이 달라질 수 있다.

검증하려는 경로는 <b>과거 의도 정보의 소실 → 과거 동의 의미의 재해석 → 후속 개입에 대한 반응 변화 → 상담 진전 판단의 변화 가능성</b>이다. 현재는 가설이며, 각 연결을 따로 확인해야 한다.

### 내담자 내부에서는 무엇을 남기는가?

Q3 기반 내담자는 발화를 만들면서 상황 해석, 턴 목표, 반응 계획, 대화 궤적 계획 등의 확정 기록을 해당 발화와 함께 남긴다. 이와 별도로 현재 상태를 이어가기 위한 노트를 갱신한다.

| 저장 정보 | 역할 |
| --- | --- |
| 공개 대화 | 상담사와 내담자가 실제로 말한 내용 |
| 현재 노트 | 다음 턴에 전달할 현재 상태·목표·이유 등의 요약 |
| 발화별 확정 내면 기록 | 그 발화를 생성한 당시의 해석·목표·반응 계획 등을 발화와 연결해 보존 |

여기서 “내면 원본”은 저장된 확정 필드이며, 모델의 전체 비공개 추론문을 뜻하지 않는다.

### A/B의 차이

| 입력 | A: summary\_only | B: intent\_linked |
| --- | --- | --- |
| 공개 대화·프로필 | 동일 | 동일 |
| 현재 상태·목표·이유 포함 노트 | 동일 | 동일 |
| 분기 시점까지 완료된 전체 턴의 발화별 내면 기록 | 추가 입력하지 않음 | 추가 입력함 |
| 첫 상담 개입 문장 | 같은 개입 안에서 동일 | 같은 개입 안에서 동일 |

A의 노트에서 이유를 일부러 제거하지 않는다. <b>이유를 담을 수 있는 요약으로도 충분한지</b>가 비교 대상이다. B의 기록은 입력에 자동 추가하며, 모델이 과거 기록 조회 도구를 선택해서 불러오는 방식은 아니다.

### 같은 과거에서 자동으로 분기하는 순서

1. 공통 대화를 A 조건으로 내담자 n턴까지 생성한다.
2. 해당 시점의 공개 대화·현재 노트·내면 기록을 고정한다.
3. 상담사 모델은 공개 대화만 보고 적용 가능한 수락 장면과 I1/I2 개입 문장을 한 번 생성한다. 비공개 내면은 받지 않는다.
4. 같은 시점에서 네 조건으로 분기한다.

|  | A: 노트 | B: 노트 + 당시 기록 |
| --- | --- | --- |
| I1: 실행 구체화 | A × I1 | B × I1 |
| I2: 현재 의향 확인 | A × I2 | B × I2 |

5. 각 개입의 A/B에 같은 문장을 전달한다. 첫 응답의 특성 라우터 선택도 공유한다. 각 조건을 반복 생성해 반응을 독립 저장한다.
6. 분기가 모두 끝나면 <b>공통 경로에서 한 턴을 더 생성</b>하고 다음 시점에서 다시 분기한다. 분기 대화는 공통 경로에 합치지 않는다.

<b>비교는 같은 행 안의 A/B가 기본이다.</b> A × I1과 B × I2를 직접 비교하면 기억과 개입의 차이가 섞인다.

### 첫 탐색의 기본값

- 공통 내담자 2\~20턴에서 매 턴 분기.
- 분기 후 내담자 1턴, 조건별 3회 반복.
- 모든 시점이 적합하면 분기 응답 228개. 공통 대화와 내부 모델 호출은 별도.
- 적합한 공개 수락 장면이 없거나 개입이 부적합하면 사유를 남기고 다음 시점으로 진행.
- 전체 기록이 입력 문자 예산을 넘으면 자동으로 자르지 않고 오류로 남김.
- 여러 턴으로 늘리면 첫 반응 이후 상담사는 각 분기의 이력에 맞춰 발화하므로 이후는 동일 입력 비교가 아닌 대화 궤적 비교.

## 6. 결과에서 무엇을 확인할 것인가?

### 단순한 문장 차이와 기억 효과를 구분한다

LLM은 같은 조건에서도 다르게 말할 수 있다. 따라서 “A와 B의 문장이 달랐다”만으로 효과라고 보지 않는다. 당시 기록과 후속 반응 사이에 내용상 연결이 있는지, 반복에서도 유사한 경향이 나타나는지 확인한다.

| 관찰 항목 | 확인 질문 |
| --- | --- |
| 과거 의미 유지 | 그때의 동의·거절·보류 이유를 근거 없이 바꾸지 않는가? |
| 현재 변화 반영 | 이후 경험이나 의향 변화가 있었다면 함께 반영하는가? |
| 개입 반응 | 같은 기억 조건에서도 개입 맥락에 맞게 반응하는가? A/B 차이가 I1/I2에서 달라지는가? |
| 상담 진전 판단 | 형식적 동의를 실제 변화 의지로 오인하는지 별도 평가할 수 있는가? |

### 가능한 결과와 해석

| 관찰 결과 | 해석 가능한 범위 |
| --- | --- |
| A/B 모두 과거 이유와 현재 변화를 잘 반영 | 해당 상황에서는 현재 노트·공개 대화만으로 충분할 수 있다. |
| B에서 당시 이유를 반영한 반응이 반복적으로 늘고, 맥락 적합성도 높음 | 해당 조건에서 <b>전체 내면 기록 추가의 유용성</b>을 지지할 수 있다. |
| B에서 과거 이유만 반복하고 실제 의향 변화를 무시 | 원본 제공이 과거에 고착시키는 부작용일 수 있다. |
| 문장만 다르고 과거 의미·개입 반응에는 체계적 차이가 없음 | 생성 변동일 가능성이 있으며 기억 효과의 근거로 부족하다. |
| 비공개 이유가 이미 공개 대화나 노트에 충분히 남아 있음 | 기록 추가의 이득이 작을 수 있다. 정보 중복 정도를 함께 봐야 한다. |

### 현재 설계가 말해주지 않는 것

- B에는 기록 묶음이 더 들어간다. 따라서 효과가 나도 <b>특정 한 턴을 기억한 효과</b>, <b>발화와 의도를 연결한 방식의 효과</b>, <b>정보량 증가의 효과</b>를 모두 분리한 것은 아니다.
- 공통 경로는 A가 방문한 상태들이다. B로 진행한 전체 상담의 우월성을 비교하는 실험은 아니다.
- 자동으로 선택한 개입의 실제 적합성은 사람이 원문을 확인해야 한다.
- 실제 내담자의 반응 타당성이나 임상적 유용성은 시뮬레이터의 자기 일관성만으로 입증되지 않는다.
