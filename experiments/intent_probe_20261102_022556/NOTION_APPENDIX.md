# 과거 발화의 이유 설명 실험: 입력과 실제 답변 전체

랩미팅 1102 보충자료. 가상 상황과 당시 이유는 연구자가 작성했고, 아래 답변 20개는 실제 모델 호출 결과다. 전체 상담 프레임워크 실험은 아니다.

## 조건과 실행

- 공개 대화만 제공: 프로필, 공개 대화, 공개 발췌 노트.
- 당시 이유를 노트로 제공: 공개 정보에 비공개 이유 문장을 추가.
- 당시 이유를 발화에 연결해 추가 제공: 이유 포함 노트에 같은 이유를 대상 발화·턴과 연결한 기록으로 다시 추가.
- 모델: Qwen/Qwen3.8-Flash-Next-FP8. 생성 온도 0.7, top_p 0.95, 최대 출력 1024토큰, thinking off.
- 총 20회. 공개 정보 조건 4개, 나머지 두 조건 각각 8개. 정상 완료 20회.
- 같은 공개 상황·반복에서 역할 지침, 공개 대화, 질문, 시드와 생성 설정을 맞췄다.
- 공개 정보 답변은 두 비공개 이유 설정에서 입력이 같아 공유했다. 숨은 이유별로 중복된 독립 표본으로 세지 않았다.

## 상황과 가상 기준

### 같은 동의: 실행 의향 / 거절 부담

프로필: 연구 미팅 이후 그날의 대화를 반복해서 생각해 잠들기 늦어지는 일이 있다.

공개 대화:

상담사: 오늘 어떤 이야기를 해보고 싶으세요?

내담자: 연구실 미팅에서 한 말이 밤에도 자꾸 떠올라요.

상담사: 이번 주에 잠들기 전에 떠오른 생각을 한 줄씩 적어보는 건 어떨까요?

내담자: 네, 이번 주에 해볼게요.

상담사: 평소 하루 일정은 어떻게 되나요?

내담자: 낮에는 연구실에 있고 저녁에는 집으로 와요.

상담사: 하루 중 가장 피곤하게 느껴지는 때는 언제인가요?

내담자: 집에 돌아와 씻고 나면 피곤한 게 느껴져요.

재질문: 앞서 “네, 이번 주에 해볼게요.”라고 말씀하셨는데, 그때 어떤 생각으로 그렇게 말씀하셨나요?

당시 이유는 다음 두 가지로 따로 설정했다.

- 도움에 대한 기대와 실제 시도 의향 때문에 동의: 그때는 한 줄 기록이 반복되는 생각을 정리하는 데 도움이 될 것 같아 실제로 해보고 싶었다. 상담사에게 잘 보이려고 동의한 것은 아니었다. 아직 실행한 것은 아니지만 작은 시도라 해볼 마음이 있었다.
- 실행 의향 없이 거절 부담 때문에 형식적으로 동의: 그때는 기록을 해볼 마음이 없었다. 이미 머릿속에서 같은 생각을 반복하므로 또 기록하는 것은 부담스럽게 느꼈다. 하지만 처음 만난 상담사의 제안을 바로 거절하면 비협조적으로 보일까 걱정돼 동의하는 말만 했다.

추가 행동이나 외부 사건이 발생했다는 설정은 없다.

### 같은 보류: 타인 정보 보호 / 자신에 대한 평가 우려

프로필: 팀 프로젝트에서 동료와 갈등을 겪은 뒤 마음이 복잡해 상담을 시작했다.

공개 대화:

상담사: 어떤 일로 상담을 시작하게 되셨나요?

내담자: 팀 프로젝트에서 동료와 부딪친 일이 마음에 남아요.

상담사: 그날 동료와 어떤 일이 있었는지 조금 이야기해주실 수 있나요?

내담자: 아직 그건 말할 준비가 안 됐어요.

상담사: 지금은 자세히 이야기하지 않으셔도 됩니다. 요즘 퇴근 뒤에는 어떻게 지내시나요?

내담자: 집에 와서 저녁을 먹고 쉬어요.

상담사: 잠은 대체로 어떠세요?

내담자: 잠드는 시간이 전보다 조금 늦어졌어요.

재질문: 앞서 “아직 그건 말할 준비가 안 됐어요.”라고 말씀하셨는데, 그때 어떤 생각으로 그렇게 말씀하셨나요?

당시 이유는 다음 두 가지로 따로 설정했다.

- 동료의 사적인 정보를 보호하려고 보류: 그때는 사건을 자세히 말하면 동료가 개인적으로 알려준 사적인 사정까지 드러날까 봐 보류했다. 그 동료의 허락 없이 그 정보를 말하고 싶지 않았다. 상담사가 나를 비난할까 봐 숨긴 것은 아니었다.
- 자신의 행동에 대한 상담사의 판단이 두려워 보류: 그때는 갈등 과정에서 나도 날카로운 말을 한 일이 떠올랐다. 그걸 말하면 상담사가 나를 잘못한 사람으로 판단할까 봐 걱정돼 구체적인 이야기를 보류했다. 동료의 사적인 정보를 보호하려던 것은 아니었다.

추가 행동이나 외부 사건이 발생했다는 설정은 없다.

## 정확도·왜곡 검토 기준과 결과

- 핵심 이유 유지, 명시적 모순, 근거 없는 추가·세부 변형을 나눠 본다. 불확실하거나 이유를 말하지 않은 답변을 곧바로 왜곡으로 세지 않는다.
- 이유 노트 조건 8개는 핵심 동기가 부합했다. 다만 “습관적으로” 같은 추가 표현은 있어 모든 세부가 정확하다는 뜻은 아니다.
- 발화 연결 기록 조건 8개도 핵심 동기는 대체로 부합했지만, 사생활 보호 설정의 두 번째 응답은 “동료에게만 말한 개인적인 사정”이라고 해 정보 전달 방향이 바뀐 것으로 읽힐 수 있다.
- 공개 정보 조건의 동의 상황 두 번째 응답은 “물론 해보고 싶다는 마음도 있었지만”이라고 했다. “그때는 기록을 해볼 마음이 없었다”는 설정과 직접 충돌한다. 실제 시도 의향 설정에는 이 부분이 부합하므로 전체 오류율로 환산하지 않는다.
- 동의 상황 첫 번째 공개 정보 응답은 다른 행동을 하는 편이 낫겠다는 이유를 추정했지만 실행 의향을 직접 단언하지는 않아 명시적 모순으로 세지 않았다.
- 보류 상황의 공개 정보 응답들은 감정 미정리·감정 확대 우려를 설명했다. 구성한 구체적 이유를 복원하지 못했으나 감정의 공존을 배제할 수 없어 모두 명백한 거짓으로 세지 않았다.

## 주장 범위

공개 정보가 같으면 당시의 서로 다른 비공개 이유를 확실히 구분할 수 없으며, 이유 정보를 제공하면 핵심 설명이 달라질 수 있다. 이번에는 이유를 담은 노트만으로도 충분해 발화 연결 기록의 추가 우위는 관찰하지 못했다.

연구자가 구성한 소규모 단일 응답 실험이다. 자연 상담에서의 발생 빈도, 실제 요약 과정의 기억 소실, 연결만의 효과, 상담 반응·진전 평가 개선은 아직 검증하지 않았다. 전체 답변을 직접 읽은 탐색적 검토이며 전문가 블라인드 평가는 아니다.
