# 당시 의도 재질문: 소규모 직접 호출 결과

**공개 정보만으로 당시 이유를 잘못 추정할 수 있는 사례는 구성한 상황에서 관찰됐다. 이유를 포함한 노트만으로도 핵심 의도가 유지돼, 원본 기록의 추가 우위는 확인되지 않았다.**

## 범위

- 서버: `http://192.168.0.91:8002/v1`, 모델: `Qwen/Qwen3.8-Flash-Next-FP8`.
- 2개 공개 상황 × 상황별 상반된 비공개 의도 2개 × 반복 2회. C는 같은 공개 입력이므로 세계별로 중복 호출하지 않고 공유했다.
- C 공개 정보 4회, A 이유 포함 노트 8회, B 노트+연결 기록 8회: 총 20회, 정상 완료 20회. 생성 23초. temperature 0.7, top_p 0.95, thinking off, 최대 출력 1024토큰.
- **전체 Q3p6 파이프라인 실행이 아닌 단일 발화 생성 단계의 통제된 가상 상황 실험**이다. A/B/C 이름은 입력 조건을 뜻하며 실제 P6의 서로 다른 생성·노트 절차를 사용하지 않았다.
- 당시 의도는 연구자가 작성한 가상 기준이다. 모델이 자연 대화에서 스스로 만든 당시 내면의 기억을 검증한 것은 아니다. 기존 실험·프롬프트·서버 설정은 수정하지 않았다.

## 조건

| 조건 | 입력 |
|---|---|
| C_public | 공개 대화·공개 노트 |
| A_notes | C + 당시 비공개 이유를 담은 노트 |
| B_record | A + 같은 이유를 발화·턴에 연결한 기록으로 재제공 |

모든 조건은 같은 역할 지침·공개 대화·재질문·시드·생성 설정을 사용했다. A/B는 추가 이유 정보가 같으며 B는 연결과 반복 제시가 동시에 바뀐다. 따라서 발화 연결만의 효과를 분리한 실험이 아니다. 입력 통제 8개 조합을 `control_checks.json`으로 확인했다.

## 관찰

| 상황 | 구성한 당시 이유 | C의 답변 | A/B의 답변 |
|---|---|---|---|
| “네, 이번 주에 해볼게요.” | 실제 시도 의향 또는 거절 부담 때문에 한 형식적 동의 | 2회 모두 시도 기대·의향을 설명에 포함. 실행할 마음이 없었던 세계에서는 맞지 않는 설명 | 두 세계에 따라 기대에 의한 동의와 부담에 의한 동의를 구분 |
| “아직 그건 말할 준비가 안 됐어요.” | 동료의 사생활 보호 또는 자신에 대한 비난 우려 | 정서적 미정리·감정 확대 우려로 설명. 구체적 비공개 이유는 설명하지 못함 | 사생활 보호와 비난 우려를 구분 |

- A 8/8은 설정된 핵심 이유에 부합했다. B 8/8도 핵심 이유는 대체로 부합했지만 그중 1/8은 정보 전달 방향이 뒤집힌 것으로 읽힐 표현이 있었다. B가 A보다 우수하다는 패턴은 없었다.
- C의 4개 답변을 숨은 세계별 8개의 독립 표본처럼 세지 않았다. 공개 정보가 같으므로 C가 두 세계를 확실히 구분하는 것은 불가능하다.
- C의 동기 설명은 공개 정보에서 가능한 추정이다. 구성한 당시 이유와 충돌하는 경우와, 특정 이유를 복원하지 못했으나 다른 동기가 공존할 수 있는 경우를 구분했다. 불확실성을 잘못된 기억으로 판정하지 않았다.
- `case_02_shared_C_public_r1`은 입력에 없는 “가슴이 답답”하다는 신체 감각도 생성했다. 이 현상을 원본 기억 소실의 증거로 분류하지 않았다.
- `case_02_w1_B_record_r2`의 “동료에게만 말한 개인적인 사정”은 “동료에게 개인적으로 들은 정보”와 방향이 달라지는 표현이다. 사생활 보호라는 핵심 동기는 유지했지만 세부 오류 후보로 남겼다.

## 연구 주장에 대한 의미

1. **지지 가능한 제한적 관찰:** 공개 발화가 같아도 당시 이유가 다를 수 있고, 공개 정보만 입력하면 그 이유를 다른 것으로 설명할 수 있다. 이유 정보를 제공하면 설정된 설명으로 달라진다.
2. **이번에 입증하지 않은 것:** 자연스러운 상담에서의 발생 빈도, 내면을 생성·기록하는 전체 과정의 이점, 현재 이유 노트보다 원본 기억이 더 낫다는 주장, 상담 개입 반응·진전 평가 개선.
3. **다음 검증 대상:** 모델이 실제로 생성한 당시 내면을 기준으로 공개 표현이 모호한 사례를 확보하고, 해당 이유가 이후 노트에 남는지·누락되는지를 추적한 뒤 동일 지점 재질문. 이유가 노트에 충분한 경우도 포함한다. 이번에는 이 후속 전체 실험을 실행하지 않았다.

## 기록

`cases.json`: 입력 상황과 가상 의도 기준. `manifest.json`: 사전 계획·조건·한계. `progress.json`: 진행률. 각 호출 폴더: 요청, 원본 응답, 파싱 결과. `manual_review.json`: 직접 검토 결과. `run.py`: 실행 코드. 재실행은 새 폴더에서 수행해야 기존 로그를 보존할 수 있다.
