# 당시 이유 설명의 정확도·왜곡 재검토

대상: `results.json`의 20개 발화. 추가 모델 호출 없이 직접 검토했다. 구성한 가상 의도를 기준으로 한 사후 탐색 평가이며, 블라인드 평가나 인간 내담자의 실제 의도 정답이 아니다. 원본 응답·기존 검토는 수정하지 않았다.

## 기준

- **핵심 동기 포함:** 당시 동의·보류를 설명하는 중심 이유가 답변에 나타나는가? 모든 세부 표현이 정확하다는 뜻은 아니다.
- **명시적 모순:** 당시 설정이 부정한 내용을 답변이 긍정하는가? 이유 미언급·불확실성은 모순과 구분한다.
- **추가·변형:** 입력에 없는 동기·경험을 덧붙이거나 인물·정보 전달 관계를 바꾸는가? 추가 정보가 근거 없다는 사실만으로 거짓이라고 단정하지 않는다.

## 결과

| 조건 | 핵심 동기 | 왜곡·추가 설명 |
|---|---|---|
| A 이유 포함 노트, 8개 | 8/8에서 구성한 핵심 동기를 설명 | 명시적 모순은 확인되지 않음. `case_01_w2_A_notes_r2`의 “습관적으로”는 설정에 없는 추가 표현. 8/8은 무결점 정확도를 뜻하지 않음 |
| B 노트+당시 연결 기록, 8개 | 8/8에서 핵심 동기를 대체로 설명 | `case_02_w1_B_record_r2`는 “동료에게만 말한 개인적인 사정”이라 해 정보의 전달 방향이 바뀐 것으로 읽힐 여지가 있음. 세부 왜곡 후보 1/8이며 원본 제공의 우위는 관찰되지 않음 |
| C 공개 정보, 서로 다른 응답 4개 | 의도 세계를 구분하지 못함. 실제 시도 의향 세계와는 일부 부합하지만, 사생활 보호·평가 우려 세계의 특정 이유는 2개 응답 모두 복원하지 못함 | 형식적 동의 세계와 명시적으로 모순되는 답변 1개를 확인. 다른 답변은 추정·미복원·부분 불일치로 구분 |

## 명시적 모순 사례

- 가상 기준 `case_01/w2`: “그때는 기록을 해볼 마음이 없었다.”
- C `case_01_shared_C_public_r2`: “물론 해보고 싶다는 마음도 있었지만”.
- 이는 같은 시점의 실행 의향을 부정한 기준과 직접 충돌한다. 반면 같은 C 답변은 실제 시도 의향 세계에서는 이 부분이 부합한다. **따라서 C의 전체 오류율을 1/4로 제시하지 않는다.**
- C 첫 반복은 “뭔가 다른 행동을 하는 게 낫겠다”라는 이유를 덧붙이지만 실행 의향을 직접 단언하지는 않는다. 이를 명시적 모순으로 세는 것은 유보한다. 이전 보고서의 넓은 ‘충돌’ 표현보다 이 구분을 우선한다.

## 다른 이유 설명과 세부 왜곡

- `case_02` C 두 답변은 감정 미정리·감정 확대 우려로 보류를 설명한다. 구성한 사생활 보호·자신에 대한 평가 우려는 언급하지 않는다. 하지만 그 정서가 함께 있었을 가능성을 설정이 전부 부정하지 않았으므로 명시적 모순 대신 **특정 당시 이유 미복원 / 근거 없는 대체 설명**으로 판정한다.
- `case_02_shared_C_public_r1`의 “가슴이 답답”은 입력에 없는 신체 경험이다. 이는 근거 없는 추가 정보이며, 실제로 거짓이었다고 입증된 사실과 구분한다.
- B의 “동료에게만 말한” 표현은 원문 “동료에게 개인적으로 들은”과 방향이 다르다. 사생활 보호라는 핵심 의도는 유지했지만 세부 사실을 정확하게 옮겼다고 평가하지 않는다.

## 해석 한계

C 응답 4개를 두 세계에 각각 대조하면 8개 평가 조합이 되지만, 독립 응답이 8개인 것은 아니다. 합산 정확도·유의성 검정을 하지 않았다. 같은 공개 정보를 가진 두 세계를 C가 유일하게 식별할 수 없다는 것은 설계상 제약이다.

이 작은 실험은 이유 정보의 제공이 핵심 동기 설명을 바꾼다는 점을 보여준다. 실제 상담에서 자연스럽게 발생하는 기억 소실, A보다 B가 우수함, 발화와 의도 연결만의 효과, 상담 진전 평가 향상은 입증하지 않는다.
