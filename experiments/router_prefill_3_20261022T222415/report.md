# 특성 라우터 prefill 3회 실험

## 목적과 조건
추론 길이가 아니라 현재 맥락 → 개인 정보의 관련성 → 근거 있는 선택으로 이어지는 판단 방향을 확인한다.

- 버전 Q2a_prefill_test, 모델 Qwen/Qwen3.8-27B-FP8, 기존 localhost:18001.
- 입력: 실제 세션 261022_183930의 두 번째 내담자 생성 직전 라우터 입력. 그룹1 gold_001, 특성 12개·배경 5개, 공개 대화·기존 내면 노트 포함.
- 현재 라우터 system/schema를 모든 조건에 동일 적용. 이전 로그의 구형 지침을 그대로 비교한 실험은 아니다.
- temperature 0.7, top_p 0.95, seed 42, max_tokens 8192. thinking_token_budget 미설정. 세 조건에서 prefill만 다름.
- 조건당 라우터 호출 1회, 총 3회. 메인/appraisal/발화/노트 생성은 실행하지 않음. 실제 사용 중 prefill 파일은 변경하지 않음.
- 문구 원문: conditions.json. 실제 입력: input.json, 조건별 request.json·prompt.txt.

## 핵심 관찰
세 조건 모두 실제 출력이 `\n</think>`로 시작했다. 새로 생성한 reasoning은 줄바꿈 하나뿐이다. prefill이 추론 입력 안에 들어갔고, Python이 미리 닫는 태그를 넣거나 요청에 추론 한도를 걸지 않았음을 실제 전송 본문으로 확인했다. 따라서 이번 3회에서는 추론 궤적의 방향·반복·근거 검토를 관찰할 수 없다. 짧아졌다는 이유로 개선이라고 평가하지 않는다.

이는 모델/디코딩 경로에서 나온 출력이다. 요청에 명시적인 추론 제한은 없지만 서버 내부 정책까지 확인한 것은 아니다. 완결된 절차 설명이 이미 생각을 마친 문맥처럼 작용했을 가능성은 후속 가설이며 확정 원인은 아니다.

## 조건별 결과
| 조건 | prefill 방향 | 선택 수 | 최종 근거 평가 |
|---|---|---:|---|
| A | 현재 질문·참여 요청 → 특성 → 배경 → JSON | 3 | 자기개방의 어려움·감정 은폐·거리 두기를 연결함. 다만 현재 초대가 위협적으로 받아들여지고 표면적 증상으로만 답할 것이라는 예측까지 확대됨. |
| B | 대화/노트·특성·배경의 근거 연결, 기록과 해석 구분 | 5 | 실제 출처를 많이 언급하지만 근거보다 강한 결론이 생김. 상담사의 인정이 내담자가 처음 감정을 외부에 드러낸 순간이라는 설명은 직전 공개 발화와 맞지 않음. ‘이상하지 않나’를 확인받아야만 자기감정을 드러낼 수 있다는 필수 조건도 원문에 없음. |
| C | 각 특성의 정보 기여도, 공유 배경 허용 | 4 | 핵심 신념·감정 노출에 대한 태도·감정 은폐·거리 두기를 구분하여 연결. 노트의 미공개 내용과 공개 발화를 구분한 설명이 상대적으로 구체적. 다만 상담사가 아직 듣지 못한 반복 거리 두기 패턴을 탐색하려고 질문했다고 목적을 구체화함. |

- 세 조건 모두 JSON/ID 검증 및 정상 종료: 3/3. 이는 의미적 타당성과 별개다.
- reasoning 궤적 관찰 가능: 0/3. 근거 판단은 최종 relevance 텍스트에 대한 직접 검토다.
- 현재 반응/행동까지 추정하는 설명: 세 조건 모두 존재. 추정 자체가 항상 부적절한 것은 아니나, 정보 선정 단계의 설명이 메인의 반응 판단을 선행할 가능성을 살펴볼 필요가 있다.
- 같은 근거의 반복 검토·불필요한 재선정: trace가 없어 판정 불가.
- 메인 발화 품질·노트 일관성·다른 프로필 일반화: 실행 범위 밖.

## 대표 근거
A: “내담자는 진짜 감정을 드러내는 것을 끔찍하게 느끼는 채로 응답하게 될 가능성이 높다.”
B: “상담사가 무기력감을 인정해 준 것은 내담자가 처음으로 그 감정을 외부에 드러낸 순간” — 앞선 내담자 발화에 이미 수면 문제·무기력감이 있음.
B: “‘이상하지 않나’를 확인받아야만 자기감정을 드러낼 수 있다는 내부 규칙” — 입력은 그렇게 보이지 않았으면 한다는 바람/걱정이지 확인을 자기개방의 필수 조건으로 정한 기록은 아님.
C: “이 반복된 거리 두기 패턴이 현재 상태에 어떤 비중을 차지하는지 탐색하는 질문” — 공개 발화에는 아직 여러 관계에서의 반복 패턴을 밝히지 않았으며 상담사의 실제 문장은 가장 무거운 부분을 묻는 열린 질문임.

## 판단
어느 조건도 이번 실험만으로 채택하지 않는다. C의 최종 근거는 개인 정보의 서로 다른 기여를 구분한다는 점에서 후속 후보이지만, 실제 추론 흐름이 개선됐다고 말할 수 없다.

다음 가설은 절차 계획을 완결해서 넣기보다 실제 첫 판단을 시작하는 미완성 문장으로 이어 쓰기를 유도하는 방식이다. 예: `The counselor's current question invites the client to`로 시작하여 질문의 성격을 모델이 직접 완성하게 한다. 이번에는 추가 호출 없이 3회에서 종료했다.

## 사용량
입력/전체 출력 토큰은 A 3015/694, B 3023/1010, C 3028/1115. 모든 출력의 대부분이 최종 JSON이다. 조건별 segment_token_counts는 각 문자열을 독립적으로 재토큰화한 참고치로 API가 보고한 reasoning 토큰 통계가 아니다.

## 한계
한 체크포인트에서 각 1회뿐이다. 고정 seed도 문구의 인과적 효과나 재현성을 보장하지 않는다. 이전에 생성된 노트의 모순 가능성도 그대로 유지한 재생 실험이다. 자동 평가 LLM은 사용하지 않았다. 시각화 화면이 아니라 실제 wire request와 raw completion, 최종 원문을 검토했다.
