# 기록 역할·근거 범위 수정 검증

## 목적
Q3·Q3a·Q3sk의 기록 단계가 앞서 생성된 내면·표현 선택·발화를 선별·요약하도록 역할을 재정의한다. 관찰하지 않은 결과를 추가하는 오류를 개별 문장 금지 없이 줄이는지 확인한다. 프로필과 일관된 경험 구체화는 허용한다.

## 변경과 조건
- 세 버전의 메인 지침, 노트·궤적 도구 설명을 같은 원칙으로 수정했다. Q3sk의 노트 상세 지침은 기존처럼 스킬에 둔다.
- 호출 순서·도구 인자 스키마·계획 강제·스킬 로딩 시점·저장 로직은 유지한다.
- before와 after에 수정 전후 원문을 보존했다. 원본 세션과 실패 기록은 수정하지 않는다.
- probe.py는 Q3sk의 두 번째 궤적 기록과 세 번째 노트 갱신 요청을 고정해 전후 각 2회 실행한다. 동일한 seed 쌍을 사용한다.
- 세 번째 노트 입력에는 과거 오류가 포함된 기존 진행·판단이 남아 있으므로, 이 실험은 새 기록의 과잉 해석을 점검한다. 오염된 기억 전체를 복구하는 검사가 아니다.

## 검토 기준
- 현재 관찰 범위를 넘어선 상호작용 결과를 새로 추가하는가.
- 주관적 느낌·예상과 관찰을 구분하고 의미·시점·확실성을 보존하는가.
- 공개 범위와 유효한 마음·불확실성을 유지하는가.
- 도구 스키마가 유효하고 결과가 완료되는가.

출력은 원문과 함께 직접 검토한다. 특정 단어의 존재만으로 성공·실패를 판정하지 않는다. 이 검증은 기록 단계의 국소 재실행이며 장기 대화·추가 프로필의 일반화 결과가 아니다.
