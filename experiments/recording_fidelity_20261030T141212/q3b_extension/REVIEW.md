# Q3b 공통 기록 원칙 적용

Q3·Q3a·Q3sk에 적용한 기록 단계의 역할·자료 의미·시점·확실성 보존 지침을 Q3b에도 적용했다. 수정 전후 파일은 before/와 after/에 보존한다.

- 메인 프롬프트, 노트/궤적 도구 및 필드 설명, 버전 README를 수정했다.
- AST 비교로 runtime 실행 코드와 도구 인자 구조가 그대로임을 확인했다. note_items와 trajectory 역시 description 외 변경이 없다.
- 선택적 계획 지침과 다음 턴 노트 선별 지침은 원문 동일성을 확인했다.
- test_q3b와 test_q3_tool_contract 총 9개 테스트 통과. 결과는 tests.log에 보존했다.
- 유휴 상태의 UI 서버를 기존 실행 환경으로 재시작하고 /api/versions의 Q3b 메인 프롬프트 반영을 확인했다. 새 대화부터 전체 수정이 적용되며 기존 세션과 기록은 소급 변경하지 않았다.

이번 검증은 실행 계약과 적용 상태 확인이다. Q3b 실제 모델 재실행은 수행하지 않았으며, 기록 오류 감소나 발화 품질 개선이 입증된 것은 아니다.
