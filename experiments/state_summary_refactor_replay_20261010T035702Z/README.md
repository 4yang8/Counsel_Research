# state_summary 의미 조회·통합 요약 구성요소 확인

범위: [OBJECTIVE.md](OBJECTIVE.md). 실제 요청·응답·사용량은 [replay.json](replay.json)에 저장했다. 기존 세션 DB는 수정하지 않았다.

- 실제 Gemma 의미 조회: 네 개 원문 중 동료에게 직접 평가를 확인하자는 제안을 처음 거절한 3턴을 올바르게 선택했다. 부모에게 원문을 반환하는 구조는 유지됐다.
- 실제 Gemma 통합 요약: 안도 → 구체 질문과 행동 제안에 경계 → 제안 철회 후 다시 안도하되 낮은 자기개방·변화 자신감 유지라는 흐름을 한 문단으로 출력했다.
- 요약의 관계 표현은 여전히 넓게 압축된다. “거절해도 실망하지 않는다”라는 말과 내담자의 “관계를 망치지 않는다”는 해석을 “관계에 영향이 없음을 확인”으로 합쳐 표현했다. 원문과 해석 주체를 완전히 구분하는 품질을 보장한 검증은 아니다.
- 내담자의 자발적인 도구 선택 또는 새 연속 상담 발화의 품질은 이번 구성요소 재실행에서 검증하지 않았다.

서버 자동 테스트 25개와 브라우저 검증을 통과했다. 새 프롬프트의 공개/비공개 경계, 같은 턴의 role:tool 주입, 실제 발화만의 다음 턴 이월, 의미 조회 결과 원문 보존, 잘못된 ID 거부, 기본 버전 보존과 UI 표기를 확인했다.
