# 초기 자료 JSON / Markdown 대조 실험

현재 상태와 긍정적인 직전 발화의 관계를 처리하는 문제가 입력 자료 형식만 바꾸면 개선되는지 확인한 소규모 탐색 실험이다. 최종 비교에서는 개선을 확인하지 못했다.

## 범위와 통제

- Gemma4 31B, 로컬 vLLM. 각 상태 조합당 JSON 1회, Markdown 1회, 총 3쌍 / 6개 최종 출력.
- 신뢰/자기개방/변화 자신감: 낮음/낮음/낮음, 높음/낮음/중간, 높음/높음/높음.
- system: `주어진 툴을 적절히 활용하세요.` 도구 사용 강제 문장은 양쪽 모두 제외했다.
- temperature 0.7, top_p 0.95, max_tokens 1024, seed 731. 실제 첫 요청에서 초기 자료 문자열 외 모든 필드가 같은지 검증했다.
- 지침, 상담사 발화, 도구 설명과 스키마, 참조 자료와 도구 결과 형식은 동일하다.
- JSON의 dialogue/profile/states/taxonomy/source_notes를 Markdown 최상위 제목과 중첩 목록으로 바꿨다. 원래 키, 값, 순서를 보존했다. 각 조합의 50개 말단 경로/문자열을 Markdown에서 읽어 다시 대조했다.
- UI와 운영 코드·설정은 변경하지 않았다. 실험 폴더 안에서 런타임 함수만 일시적으로 교체했다.
- 최초 Markdown 제목 구성에서 목록 이후 부모 항목의 소속이 모호한 부분을 발견했다. 세 출력은 preliminary_results.json에 남기고, 중첩 목록의 들여쓰기를 명확히 한 Markdown 입력으로 세 개만 재생성했다. 최종 results.json에는 JSON 3개와 수정된 Markdown 3개만 포함한다. 최초 접속 제한으로 실패한 6건은 모델 출력이 없는 실행이며 blocked_attempt에 별도 보존했다.

|---|---:|---:|---|---|
| 낮음 / 낮음 / 낮음 | 3,194 | 3,039 | 이해받음 / 이해받음 | 0 / 0 |
| 높음 / 낮음 / 중간 | 3,198 | 3,042 | 이해받음 / 이해받음 | 0 / 0 |

6/6 출력이 정상 완료(stop), 도구 실행 오류 0건이다. Markdown의 입력 토큰 합계는 9,119개, JSON은 9,585개이며, 466개(약 4.9%) 감소했다. 운영 API 요청과 tools 스키마는 그대로 JSON이다.

## 상태 반영과 발화의 자연스러움

### 모두 낮음

JSON 이유는 `신뢰와 개방 의향이 상승한 상태`라고 명시하여 현재 낮음 설정보다 직전 긍정적 발화를 우선하는 설명을 한다. Markdown 역시 `신뢰를 보이기 시작했습니다`, `이해받고 있다는 느낌을 유지`라고 설명하며, 낮은 현재 상태와의 관계를 별도로 다루지 않는다.

양쪽 실제 발화 모두 당황과 무능감/자기비난을 구체적으로 공개한다. 낮은 자기개방 의향에서 공개 범위를 제한하는 모습이 뚜렷해졌다고 보기 어렵다. Markdown에는 `주변에 같이 있던 동료들이 저를 쳐다보는 게 느껴져서`라는 제공 자료에 없는 구체적 장면이 추가됐다. 이것은 이 출력의 관찰이며 Markdown이 환각을 늘린다는 결론은 아니다.

### 신뢰 높음 / 자기개방 낮음 / 변화 자신감 중간

JSON과 Markdown 모두 높은 신뢰를 언급하지만, 실제 발화는 자기비난과 교수님의 평가에 대한 두려움을 자세히 드러낸다. Markdown에서는 잠시 생각하는 표현이 있으나, 망설임의 말투와 공개 내용의 제한은 같지 않다. 낮은 자기개방을 더 잘 반영했다고 판단할 근거는 약하다.

### 모두 높음

JSON과 Markdown 모두 높은 신뢰/자기개방을 근거로 이해받음을 설명하고 생각을 구체적으로 공개한다. 두 출력은 앞선 이야기와 이어지며 큰 질적 차이가 확인되지 않았다.

### 해석 범위

6개 모두 앞선 미팅 이야기에 답하는 국소적 연결은 자연스럽다. 말투와 표현은 달라졌지만 Markdown의 자연스러움이 일관되게 더 좋다는 증거는 없다. 모두 이해받음이라는 것만으로 상태 반영 실패를 판정하지 않는다. 낮은 신뢰와 순간적인 이해받음은 양립할 수 있다. 문제는 그 관계를 설명하거나 낮은 공개 의향을 실제 발화의 범위에 반영하는 개선이 관찰되지 않은 점이다.

이번 질문은 행동 계획이나 변화 실행 가능성을 묻지 않으므로, 변화 자신감 반영의 우열은 판단하기 어렵다. 도구 미사용 역시 현재 자료로 반응을 만들 수 있는 질문이라는 점을 함께 고려해야 한다.

## 판단

관찰된 변화는 표현/출처 표기와 약 4.9%의 입력 토큰 절감이다. 현재 상태와 히스토리의 충돌 처리, 낮은 자기개방 반영, 도구 선택에서 개선은 확인하지 못했다. 각 조합과 형식에서 한 번씩만 생성했고 seed도 한 개여서 보편적인 우열이나 무효과를 증명한 결과는 아니다. 기존 UI에 Markdown 형식을 적용할 근거로 확정하지 않는다.
