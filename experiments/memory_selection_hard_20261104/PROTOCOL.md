# 실행 전 고정한 실험 계획

## 질문과 범위

인공적으로 직접 작성한 한 내담자의 60개 과거 턴에서, 현재 질문에 필요한 당시 비공개 기록을 RAG와 전체 기록을 읽는 LLM이 얼마나 정확히 선별하는가? 대화·기록 생성, 후속 발화 생성, 상담 효과는 이번 실험 범위가 아니다. 기존 analysis-generated-dialogue 검증 절차에 따라 입력·선별·평가를 분리한다.

## 데이터

- RECORDS.md: 사람이 검토할 후보 기록. records.json: 같은 내용을 실행용으로 표현한 파일.
- QUESTIONS.md / questions.json: 10개 공개 질문. 모두 60개 기록 이후에 묻는다.
- GOLD.md / gold.json: 실행 전에 고정한 평가 기준. 어떤 모델에도 제공하지 않는다.
- 8개는 원본 근거가 있고, 2개는 질문이 가정한 사건 자체가 기록에 없다.
- 동일한 말·인물·상황의 반복, 과거와 현재 의도 변화, 가상 역할극과 실제 사건 혼동, 정보가 없는 상황을 포함한다.
- 최초 발화의 직접 원본은 core, 후일 회고와 주변 맥락은 supporting. 모든 관련성을 이 구분만으로 설명할 수 없으므로 선택된 원문도 사후 사람이 확인한다.

## 통제와 조건

공통: Qwen/Qwen3.8-Flash-Next-FP8, temperature 0.7, top_p 0.95, max_tokens 4096, reasoning_effort low. 반복 seed 1104/1105. 프로필·전체 공개 대화·현재 질문·후보 60개·상위 최대 3개라는 예산이 동일하다. 문서 순서는 시간순으로 고정한다. 두 방법의 실행 순서를 번갈아 배치한다. 답을 본 뒤 프롬프트·정답·사례를 바꾸지 않는다.

1. RAG: 생성 모델이 공개 대화와 질문만 보고 검색어 1개 작성 → 실제 memory_access.retrieve로 Qwen3-Embedding-4B 임베딩 및 cosine Top-3. 쿼리 지시문·청크 포맷·임계값 없음은 현재 구현과 동일. 현재 UI의 선택적 도구 호출과 달리 이번 실험은 검색을 항상 실행한다. 도구 호출 여부와 선별 품질을 분리하기 위한 component probe다.
2. LLM 전체 읽기: 현재 Q3select selector.md를 그대로 사용. 공개 대화·질문과 60개 원본 청크 전체를 보고 0~3개 ID 선택. 요약·정제는 하지 않으며 선택 원본을 코드로 가져오는 기존 방식이다.

한 턴 청크는 turn + inner + utterance다. 별도 counselor_utterance 필드는 기존 RAG와 동일하게 임베딩에서 제외되며 전체 공개 대화에는 있다. scene은 인공 내면 기록에 포함된 상황 맥락이다. 원본 UI 데이터와 표현 방식이 같지는 않으므로 이 차이도 일반화 한계다.

## 평가

- core recall: 필수 원본 중 선택한 비율. 8개 질문 × 2회 = 16개 trial에서 평균.
- all-core / any-core: 원본 전부 / 하나 이상 확보한 trial 수.
- relevant precision: 선택 중 core 또는 supporting인 비율. 빈 선택은 undefined로 별도 취급하며 원본 누락 지표에는 반영한다.
- irrelevant count / confusable count: 비관련 또는 사건·시점 혼동 위험 기록 선택 개수. 선택만으로 실제 답변 왜곡을 단정하지 않는다.
- 없는 사건: 빈 선택 여부를 별도 집계한다. 임계값 없는 RAG는 구조적으로 빈 결과를 낼 수 없으므로 이 결과를 answerable 검색 성능과 합쳐 승패를 결정하지 않는다.
- 지연시간: RAG는 검색어 생성 + 임베딩/검색 합, LLM은 선별 생성 시간. 최초 색인 비용과 이후 캐시 상태를 각 retrieval에 저장한다. 서버 상태·입력 캐시의 영향을 받는 소규모 관측값이다.
- 토큰: 생성 서버의 input/output 토큰 보고. 임베딩 추론 비용은 해당 수치에 포함하지 않으며 검색 기록의 문서 수·지연을 함께 확인한다. 후속 발화 비용도 제외한다.

## 해석 제한

이 자료와 정답은 같은 분석자가 직접 구성했고 정답은 외부 임상 검증을 받지 않았다. 중립적인 현실 분포 표본이나 신규성 근거가 아니다. 동일 사례의 두 번 호출은 독립된 두 사례가 아니다. 정밀한 순위평가에는 더 다양한 내담자·사건 및 독립 정답 검토가 필요하다. 초기 선택 성능과 실패 양상만 보고하고 보편적 우열·상담 효과를 주장하지 않는다.
