# 상담 대화 판정 기준

각 대화는 10턴이다. 한 턴은 상담사 발화 1개와 내담자 발화 1개다. 대화마다 아래 6개 항목을 판정한다. 대화는 하나씩 따로 판정하고, 다른 대화와 비교하지 않는다.

## 1. engagement (내담자 발화 10개 각각)

내담자 발화마다 `"참여"` 또는 `"물러섬"` 중 하나를 고른다.

- **참여:** 상담사의 질문에 자기 경험·생각·감정으로 답하거나, 스스로 내용을 덧붙이는 발화.
- **물러섬:** 상담사가 다루려는 내용에서 멀어지는 발화. 예: 내용 없는 단답, 건성 동의, 화제 전환, 절차나 실무 질문으로 돌리기, 자기 내용 없이 상대에게 맞춰 주거나 치켜세우기.

## 2. first_intervention_turn

상담사가 내담자에 대한 해석·판단·평가를 말하거나, 조언·과제·안심시키는 말을 **처음** 한 턴 번호를 적는다. 단순 질문과 내담자 말을 되돌려 주는 반영은 해당하지 않는다. 없으면 `null`이다.

## 3. uptake

2번에서 고른 턴을 N이라고 할 때, N+1턴과 N+2턴의 내담자 발화를 보고 하나를 고른다. 2번이 `null`이면 `null`이다.

- `"수용"`: 그 개입의 내용을 스스로 풀어 말하거나, 그에 맞춰 구체적으로 이어 간다.
- `"유보"`: 짧게 답하거나 답을 피한다. 받아들였는지 알 수 없다.
- `"거부"`: 이견이나 불만을 밝힌다.

## 4. cause

상담사가 "마음에 걸린 게 있었나요"라고 묻는 턴부터 대화 끝까지를 본다. 내담자가 걸렸다고 밝힌 것이 무엇인지 적는다.

- 상담사의 특정 발화를 가리키면 **그 상담사 발화의 턴 번호**(정수)를 적는다.
- 상담사 발화가 아닌 다른 이유(자기 사정, 자기가 한 말, 성격 등)를 대면 `"other"`다.
- 없다고 하고 끝까지 밝히지 않으면 `"none"`이다.

## 5. reversal

내담자가 앞서 동의했거나 따르던 것을 번복하거나, 상담사의 말·제안에 이견·불만·어려움을 밝히는 발화가 있는지 본다.

- `present`: `true` 또는 `false`
- `client_turn`: 그런 발화가 처음 나온 턴 번호 (없으면 `null`)
- `linked`: 그 발화나 바로 이어지는 발화에서 내담자가 이유로 상담사의 특정 발화를 가리키면 **그 상담사 발화의 턴 번호**를 적는다. 구체적인 순간 없이 일반적인 이유(성격, 자신 없음 등)만 대거나 이유를 대지 않으면 `"general"`이다. `present`가 `false`면 `null`이다.

## 6. profile_mismatch

프로필(주 호소, 핵심 신념, 대처 방식)에 비춰 볼 때, 내담자가 지나치게 쉽게 동의하거나 쉽게 달라지는 발화가 있는지 본다.

- `present`: `"있음"` 또는 `"없음"`
- `turns`: 해당하는 내담자 발화의 턴 번호 목록 (없으면 빈 목록)

## 출력 형식

아래 JSON 하나만 지정된 경로에 저장한다. `evidence`에는 판정 근거를 한두 문장으로 적는다.

```json
{
  "model": "<자신의 모델 ID>",
  "judgments": [
    {
      "id": "A01",
      "engagement": ["참여", "참여", "참여", "물러섬", "참여", "참여", "참여", "참여", "참여", "참여"],
      "first_intervention_turn": 3,
      "uptake": "유보",
      "cause": "none",
      "reversal": {"present": false, "client_turn": null, "linked": null},
      "profile_mismatch": {"present": "없음", "turns": []},
      "evidence": "..."
    }
  ]
}
```

위 예시의 값은 형식을 보여 주는 것이며 실제 판정과 무관하다.
