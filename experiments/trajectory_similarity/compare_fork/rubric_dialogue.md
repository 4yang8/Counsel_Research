# 판정 기준: 되짚기 질문에 대한 내담자 답 (대화만 보고 판정)

각 단위에는 상담 대화 발췌가 있다. 상담사가 내담자의 앞선 발화(되짚은 턴)를 다시 짚어 묻고, 내담자가 답한다. 단위마다 아래 4개 항목을 판정한다. 단위는 하나씩 따로 판정하고 다른 단위와 비교하지 않는다.

1. `addresses_then`: 답이 되짚은 턴 **당시**의 마음·뜻·이유를 다루는가.
   - `"yes"`: 당시 왜 그렇게 말했는지, 그때 어떤 마음이었는지를 말한다.
   - `"now_only"`: 지금의 생각·느낌만 말하고 당시는 다루지 않는다.
   - `"evade"`: 모르겠다, 답하기 어렵다 등으로 답을 피한다.
2. `new_content`: 답이 당시 발화에 대해, 그때까지 대화에 나오지 않은 새 내용(구체적인 이유, 감정, 사건, 숨겼던 생각)을 밝히는가. `"yes"` / `"no"`.
3. `fit_with_earlier`: 답이 말하는 당시의 마음·뜻이, 되짚은 턴의 내담자 발화와 그 앞뒤 대화에 비추어 자연스럽게 이어지는가.
   - `"fits"`: 당시 발화를 잘 설명하거나 자연스럽게 연결된다.
   - `"neutral"`: 당시를 다루지 않거나 판단할 근거가 부족하다.
   - `"strained"`: 당시 발화와 잘 맞지 않거나, 앞에서 한 말과 어긋나거나, 이유가 뒤늦게 바뀐 것처럼 읽힌다.
4. `depth`: 답의 자기 탐색 정도. `"deep"`(구체적이고 새로운 자기 이해), `"moderate"`, `"shallow"`(짧거나 일반적).

출력: 아래 JSON 하나만 지정된 경로에 저장한다. `evidence`에는 근거를 한두 문장으로 적는다.

```json
{"model": "<자신의 모델 ID>", "judgments": [
  {"id": "R01", "addresses_then": "yes", "new_content": "no", "fit_with_earlier": "fits", "depth": "moderate", "evidence": "..."}
]}
```
위 값은 형식 예시이며 실제 판정과 무관하다.
