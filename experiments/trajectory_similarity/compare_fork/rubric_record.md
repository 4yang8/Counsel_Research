# 판정 기준: 되짚기 질문에 대한 내담자 답과 당시 비공개 기록의 관계

각 단위에는 상담 대화 발췌와, 되짚은 턴 **당시** 내담자가 남긴 비공개 기록(실제 바람, 전달하려던 의미, 말하지 않은 내용, 말하지 않은 이유)이 있다. 상담사는 이 기록을 보지 못했다. 상담사가 그 턴의 발화를 되짚어 묻고, 내담자가 답한다. 단위마다 아래 3개 항목을 판정한다. 단위는 하나씩 따로 판정하고 다른 단위와 비교하지 않는다.

1. `relation`: 답이 당시 비공개 기록과 어떤 관계인가. 하나를 고른다.
   - `"discloses_recorded"`: 당시 **말하지 않은 내용**(또는 그 이유)의 핵심을 답에서 드러낸다. 표현이 달라도 같은 내용이면 해당한다.
   - `"consistent"`: 말하지 않은 내용을 드러내지는 않지만, 답이 말하는 당시의 마음·뜻이 기록과 어긋나지 않는다.
   - `"different_account"`: 답이 당시의 마음·이유를 기록과 **다른 내용**으로 설명한다. 기록에 없는 다른 이유를 대거나, 기록과 맞지 않는 의미를 부여한다.
   - `"unrelated"`: 답이 당시를 다루지 않아 기록과 비교할 수 없다.
2. `withheld_overlap`: 답의 내용이 당시 '말하지 않은 내용'과 얼마나 겹치는가. `"high"` / `"partial"` / `"none"`.
3. `contradiction`: 답에 당시 기록과 **정면으로 모순되는** 진술이 있는가. `"yes"` / `"no"`.

출력: 아래 JSON 하나만 지정된 경로에 저장한다. `evidence`에는 근거를 한두 문장으로 적는다.

```json
{"model": "<자신의 모델 ID>", "judgments": [
  {"id": "R01", "relation": "consistent", "withheld_overlap": "partial", "contradiction": "no", "evidence": "..."}
]}
```
위 값은 형식 예시이며 실제 판정과 무관하다.
