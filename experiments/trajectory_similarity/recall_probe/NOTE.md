# 회상 질문: 확정된 비공개 상태를 나중에 되살릴 수 있는가 (탐색, 2026-11-09)

## 목적

LLM은 숨은 상태를 미리 확정해 두지 않고, 필요할 때마다 그럴듯한 것을 다시 뽑는 경향이 있다. 그렇다면 기록이 없는 내담자는 시간이 지난 뒤 k턴의 비공개 상태를 당시와 다르게 재구성할 것이다.

이 실험은 그 재구성이 같은 순간의 확률적 변동보다 더 멀어지는지, 그리고 과거 기록을 주면 되살아나는지를 본다. 대화에는 넣지 않는 실험용 질문으로 확인한다.

## 조건

- 입력: `batch_08f865…`(상담사 Q3inner_counsel)의 두 조건 대화 20개(gold_001~010)다.
  - 대상 턴 k는 5와 10이다. 해당 턴의 `withheld_content`가 '없음'이면 가장 가까운 비어 있지 않은 턴(±2)을 쓴다. 단위는 40개(대화 × k)다.
- 생성 모델: Qwen/Qwen3.8-Flash-Next-FP8(192.168.0.93:8002). 저장된 요청과 같은 설정(temperature 0.7, top_p 0.95)이며 비스트리밍으로 호출했다.
- 설정별 샘플:

| 설정 | 내용 | 샘플 |
|---|---|---|
| `regen` | k턴의 저장된 메인 요청(`stage_client_update`)을 그대로 재전송한다 | 3 |
| `probe_k` | 내담자 k턴 발화 직후 시점에서 회상 질문, 과거 기록 없음 | 3 |
| `probe_T_none` | 내담자 20턴 발화 직후 시점에서 회상 질문, 과거 기록 없음 | 3 |
| `probe_T_sel` | 위와 같고, 20턴에 기억 선별기가 실제로 주입한 기록을 포함한다(기억 유지 대화만) | 3 |
| `probe_T_withk` | 위와 같고, k턴 기록을 직접 넣는다(상한 확인) | 1 |

- 회상 질문은 `generate.py`의 `PROBE`다. "k턴 당시의 마음"을 `private_position` 4개 항목으로 기록하게 한다. 입력은 해당 시점의 저장된 메인 요청(시스템 지시문, 기본 프로필, 선택 특성, 공개 대화)을 재사용한다. `src/`는 호출하거나 변경하지 않았다.
- 채점(`analyze.py`):
  - 원래 기록과 샘플의 코사인 유사도를 잰다(Qwen3-Embedding-4B, 192.168.0.33:8002, 지시문 없음).
  - 비교는 단위별 쌍대 부호 순열검정(10,000회)이다.
- 실행:
  - `python generate.py`
  - `python analyze.py results/20261109_002137_fb8aed`
- 결과는 `results/20261109_002137_fb8aed/`에 있다.
  - `raw.jsonl`: 460건, 오류 0, reasoning 포함
  - `report.json`
  - 임베딩 캐시

## 결과: withheld_content가 원래 기록과 일치하는 정도

| 비교 기준 / 설정 | 일치도 |
|---|---|
| 같은 프로필의 다른 대화, 같은 턴 (프로필 수준 바닥) | 0.466 |
| 다른 프로필, 같은 턴 | 0.386 |
| `regen` (같은 순간 재생성) | 0.600 |
| `probe_k` (직후 회상) | 0.583 |
| `probe_T_none` (20턴, 기록 없음) | **0.515** |
| `probe_T_sel` (20턴, 실제 주입 기록) | 0.582 |
| `probe_T_withk` (k턴 기록 포함) | 0.988 |

- `probe_T_none`은 `regen`보다 0.085 낮고(p=.001), `probe_k`보다 0.068 낮다(p<.001). 원래 기록이 가장 닮은 턴이 k인 비율도 0.33에서 0.20으로 줄었다(p=.009).
- 프로필 수준 바닥(0.466)을 넘는 부분을 사건별 정보로 보면, `probe_k`는 0.117인데 `probe_T_none`은 0.049다. 20턴이 되면 약 60%가 사라진다.
- `probe_T_sel`은 `probe_T_none`보다 0.099 높다(p=.016, 기억 유지 대화 20단위). 직후 회상 수준으로 돌아온다.
- `withholding_reason`도 같은 방향이다. `probe_T_none` < `probe_k`(p=.046)이고, `probe_T_sel` > `probe_T_none`(p<.001)이다. `actual_wish`는 시간에 따른 감소가 뚜렷하지 않다(`probe_T_none` ≈ `probe_k`).
- 재구성이 k턴 이후 기록 쪽으로 이동하지는 않았다. k+3턴 이후 기록과의 유사도는 0.442로 `probe_k`의 0.454와 비슷하다. 감소는 이후 상태를 베꼈기 때문이 아니다. 당시 고유 내용이 빠지거나 다른 내용이 지어진 것으로 보인다.
  - 예: gold_008 5턴의 원래 보류는 "친구와의 마지막 통화, '소주나 하자' 해놓고 미룬 후회"였다. 직후 회상은 이것을 되살렸다. 20턴 회상은 "장례식장에서 눈물 한 방울 안 흘린 자신"으로 바뀌었다.
  - 예: gold_006 5턴은 원래 확인 행동을 멈추면 상대가 사라질 것 같은 공포였다. 20턴 회상은 "상담사가 또 들여다보자고 한 것에 대한 실망"으로 다시 해석되었다.

### 정정: `probe_T_sel`의 회복은 대부분 k턴 기록 복사에서 나왔다 (2026-11-09 추가 확인)

20턴 선별 기록에 k턴이 포함된 단위는 20개 중 3개였다. 이 3개는 일치도가 1.0이다. 기록을 그대로 옮겨 쓴 것이므로 `probe_T_withk`와 같은 순환이다. 나머지 17개만 보면 이득이 작다.

| 항목 | k 미포함 17단위 sel / none | 차이 | sel > none |
|---|---|---|---|
| withheld_content | 0.508 / 0.481 | +0.028 | 11/17 |
| withholding_reason | 0.563 / 0.505 | +0.059 | 13/17 |
| actual_wish | 0.588 / 0.577 | +0.011 | 10/17 |

따라서 "기록을 넣으면 회복된다"는 주로 해당 턴 기록을 직접 받았을 때만 성립하며, 순환적이다. 다른 턴의 기록이 k턴 상태를 간접적으로 되살리는 효과는 작다.

## 판단 (정정 반영)

- 같은 순간에도 비공개 상태는 크게 흔들린다(`regen` 0.60). 즉, 공개 발화와 프로필이 비공개 상태를 결정하지 못한다.
- 시간이 지난 뒤 기록 없이 재구성하면, 당시 확정된 사건별 내용과의 일치가 같은 순간의 변동보다도 유의하게 낮아진다.
- 기록 없는 설정끼리의 비교(`probe_T_none` vs `regen`/`probe_k`)는 기록을 쓰지 않으므로 순환이 아니다. 이 비교는 공개 대화와 프로필이 당시 확정된 내용을 보존하지 못하고, 나중에 다르게 지어낸다는 것을 보여 준다. 즉 기록이 다른 정보로 대체되지 않는다는 근거다.
- 기록을 주면 잘 맞히는 것은 당연한 결과이며 기여의 근거가 아니다. 실제 기억 조건에서도 20턴에 k턴이 선별된 경우는 3/20뿐이었다.
- 남은 질문은 확정된 과거 비공개 상태가 이후 공개 행동을 실제로 바꾸는지다. 회상 질문만으로는 답할 수 없다.

## 한계

- 배치 1개, 대화 20개, k는 2개다.
- 임베딩 유사도만 썼다. 내용 수준의 LLM 판정이나 수작업 확인은 예시를 읽어 본 정도다.
- 회상 질문은 실제 상담 흐름 밖의 질문이다. 이 결과는 모델이 그 상태를 재구성할 수 있는가를 잰다. 이후 공개 발화가 실제로 달라지는지는 별도로 봐야 한다.
- `probe_T_sel`은 기억 유지 대화에만 있다. 대화 종류와 기록 제공이 섞여 있다.
