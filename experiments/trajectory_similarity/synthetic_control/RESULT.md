# 첫 임베딩 점검 결과

원고를 고정한 뒤 기존 분석 코드로 40개 인공 대화를 계산했다. 결과를 확인한 뒤 대화 원고를 조정하지 않았다.

- 실행 결과: [그래프](results/20261108_095219_ffe9ea/mean_cosine.png), [수치](results/20261108_095219_ffe9ea/mean_cosine.csv), [입력 스냅샷](results/20261108_095219_ffe9ea/analysis.json)
- 모델: `Qwen/Qwen3-Embedding-4B`, 2,560차원, 턴마다 각 조건 20명 / 190쌍.
- 프로필과 상담사 질문을 제외한 내담자 발화 800개만 임베딩했다.

| 구간 | 다양성 유지 | 반응 수렴 |
|---|---:|---:|
| 1~5턴 | 0.502 | 0.502 |
| 6~8턴 | 0.428 | 0.659 |
| 9~15턴 | 0.455 | 0.632 |
| 16~20턴 | 0.495 | 0.636 |

의도적으로 공통 의미와 표현으로 바꾼 조건은 대체로 더 높은 유사도를 보였다. 처음 5턴은 같은 문장이고 곡선도 거의 같다. 동일 텍스트를 각각 임베딩했을 때 이 실행에서 관찰된 첫 5턴 최대 차이는 약 0.00037이다.

단, **16턴은 다양성 유지 조건의 유사도가 더 높다.** 각자의 과거 이유는 다르지만 “그때 괜찮다는 말은 … 뜻이 아니라 … 뜻이었다”라는 비슷한 설명 구조가 나타난다. 이 형식이 높은 유사도에 기여했을 가능성이 있으며, 어휘·구문과 심리 의미의 영향을 분리한 실험은 아니다. 곡선 한 지점만으로 심리적 차이가 사라졌다고 판단해서는 안 된다.

데이터 검증: 조건마다 20개 대화 × 20턴, 첫 5턴과 프로필은 조건 간 동일, 매 턴 20명의 문장은 서로 다름, 괄호·기호뿐인 응답 없음, 문장부호 기준 모두 1~2문장. 평균 발화 길이는 유지 46.7자 / 수렴 50.1자다. 수렴 조건 6~8턴은 고유 이유를 함께 표현해 상대적으로 길다.

해석 범위는 **강한 공통 반응으로 만든 인공 데이터의 차이를 기존 임베딩 그래프가 대체로 포착했다**는 것이다. 실제 Q3에서 내면 기록의 유무가 차이를 만든다는 증거, 미세한 심리 차이에 대한 검증, 임상적 타당성 또는 통계적 유의성 검증은 아니다.
