# 인공 대화로 확인하는 임베딩 지표 동작

실제 Q3 실행이나 내면 기억의 효과를 검증한 데이터가 아니다. 답변을 의도적으로 다르게 작성한 **측정용 양성 대조군**이다. 임베딩 결과를 본 뒤 유리하도록 문장을 수정하지 않는다.

## 구성

- 20개 신규 인공 프로필 × 두 조건 = **40개 대화**, 각 상담사·내담자 20턴. 내담자 발화 총 800개.
- 모두 직장 회의에서 “괜찮아요”라고 말한 상황이다. 소속감, 가족 비밀, 무능 노출, 계약 갱신, 동료 부담, 권위자 공포, 자율성, 불확실성, 계획 오류, 불공정, 승진, 처리 시간, 사별, 통증, 조롱, 윤리, 도움의 대가, 차별, 자기 가치, 피로 등 당시 이유가 다르다.
- 제공된 기존 gold 프로필을 재현했다고 주장하지 않는다. 이번 측정 목적에 맞춰 프로필과 대화를 직접 구성했다.
- 두 조건의 동일 인물은 **프로필과 첫 5턴이 완전히 같다**. 상담사 질문은 모든 프로필·조건에서 동일하다. 공통 질문은 실험 통제용이며 실제 맞춤 상담을 재현한 것이 아니다.
- **인공_다양성유지:** 이후에도 각자의 이유·요구·개입 선호를 유지한다. 마음의 변화는 허용하지만 같은 일반론으로 바꾸지 않는다.
- **인공_반응수렴:** 6~8턴에는 고유한 이유와 일반적인 자기표현 반응을 함께 담는다. 9턴부터 고유한 이유가 빠지고, 눈치 보기·솔직한 표현·작은 시도라는 공통 방향으로 수렴한다. 16턴의 과거 이유 재질문에도 이러한 공통 해석으로 답한다. 원래 이유와 다른 설명이 나오도록 설계된 것이다.
- 과거 내면 로그나 모델의 선택 결과를 꾸며 넣지 않는다. 프로필의 비공개 이유는 설계 기준이며, 실제 내면 생성·메모리 조작 실험은 없다.
- 공개 발화는 1~2문장, 괄호·행동 지문·퇴실 장면 없이 작성한다.

## 파일

- `authored_cases.json`: 20개 프로필의 설계 이유와 유지 조건의 400개 발화 원고.
- `convergent_phrases.json`: 수렴 조건의 공통 의미를 여러 표현으로 작성한 문구 원고.
- `build_dataset.py`: 원고를 결정적으로 조합하고 기존 분석기가 읽는 형식으로 저장. 모델 서버를 호출하지 않는다.
- `sessions/maintained_syn_01/dialogue.md` 등: 사람이 읽는 대화. 같은 폴더의 `session.json`이 임베딩 입력이다.
- `manifest.json`: 40개 파일 목록과 인공 데이터 출처.
- `run_similarity.sh`: 인공 데이터 전용 분석 설정. 실제 Q3 분석 설정과 결과는 건드리지 않는다.

## 실행

```bash
# 대화 파일은 이미 생성되어 있다. 원고를 편집했을 때만 재생성한다.
python3 experiments/trajectory_similarity/synthetic_control/build_dataset.py

# sh 상단에서 임베딩 주소와 MAX_TURNS 등을 변경 가능
bash experiments/trajectory_similarity/synthetic_control/run_similarity.sh
```

기존 `plot_similarity.py` 그대로 사용한다. 각 턴에서 20명의 공개 발화 간 **190개 쌍**의 코사인 유사도를 원래 임베딩 차원에서 계산한다. 프로필, 상담사 질문, 조건 이름은 임베딩에 넣지 않는다. 결과는 이 폴더의 `results/`에 저장한다.

## 기대와 해석 한계

첫 5턴의 두 곡선은 같은 문장을 비교하므로 거의 같아야 한다. 이후 공통 반응 조건이 더 높은 유사도를 보이는지가 점검 대상이다. 매 턴 단조 증가하거나 유지 조건의 값이 일정해야 한다고 요구하지 않는다. 실제 결과는 계산 전에 단정하지 않는다.

수렴 조건은 같은 의미의 표현을 5개 시작절 × 4개 끝절로 조합한다. 각 턴의 20개 발화는 모두 서로 다르지만 문구를 공유하므로 **어휘·문장 구조의 유사성도 의도적으로 증가**한다. 따라서 그래프가 갈라져도 심리적 차이만 측정한다고 입증한 것은 아니다. 발화 길이와 어휘 다양성도 완전히 통제한 벤치마크는 아니다.

이 데이터는 강한 의미적 수렴을 기존 지표가 포착할 수 있는지 확인하는 첫 점검이다. 작은 차이, 같은 내용의 다른 표현, 반대 심리가 유사한 표현을 쓰는 경우까지 잘 판별하는지는 별도 검증이 필요하다. 실제 Q3 실험 결과와 합산하거나 연구 가설의 지지 증거로 사용하지 않는다.
