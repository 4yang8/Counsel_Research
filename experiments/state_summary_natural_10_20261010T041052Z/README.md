# 수정 후 state_summary · 실제 상담 발화 10회

조건: [OBJECTIVE.md](OBJECTIVE.md). 결과: [report.md](report.md), [전체 입력·발화·요약](dialogue.md), [관찰 인덱스](analysis_index.json), [분포·사용량](metrics.json), [전달 검증](handoff_checks.json).

같은 세션에서 10회 시도했다. 1~8회 자발적 도구 선택 1회, 9~10회 System prompt 지시형 호출 2회. 모든 상담사 발화는 실제 상담 내용이며 함수명·시스템·DB·조회 명령을 넣지 않았다.

정상 반영 5턴 / 실패 5회. 실패는 느낌 숫자 출력 1회와 JSON 코드블록 4회. 원문을 보존했고 다음 히스토리·내면 DB에 넣거나 자동 재생성하지 않았다.

실제 코드·설정 스냅샷, 입력마다의 System prompt 및 원문 이벤트, 세션 로그·내면 DB·요약을 보존했다. 별도 로컬 서버로 실행했으며 기존 연구 코드·UI 프로세스·기본 지침을 바꾸지 않았다. 이번 결과는 단일 적응형 세션으로, 요약 유무나 독립 조건별 대조실험 결과가 아니다.
