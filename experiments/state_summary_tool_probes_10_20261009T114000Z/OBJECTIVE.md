# 실험 질문

한 세션의 10회 연속 시도에서 어떤 상담사 입력이 선택적 정보 조회를 촉발하는가? 누적 내면 trajectory 요약이 사실·주관적 해석·내면 변화를 보존하며 후속 발화는 자연스럽게 이어지는가?

# 조건

- state_summary, 프로필 001 / 히스토리 1, 기존 메인·요약 프롬프트와 도구 description 유지.
- 초기 4쌍 이후 상담사 발화 10번을 직접 입력. 직전 응답, 실제 도구 결과, 다음 요약에서 빠진 정보 등을 보고 다음 질문을 정한다.
- 허용 도구: retrieve_inner_state, retrieve_childhood, retrieve_situation. 호출 강제 API 설정 없음.
- 자연스러운 외부 사건 상세/성장 경험 질문 → 이전 내면 근거 질문 → 기록 확인 요청 → 필요시 도구 이름을 직접 지정하는 진단 요청. 유형과 목적은 probe 파일에만 저장하고 숨은 지침으로 모델에게 넣지 않는다.
- 같은 Gemma, 기존 sampling 및 토큰 제한. 선택 조회 서브에이전트의 원문 선택과 메인 활용도 확인한다.
- 실패를 골라내거나 같은 입력을 자동 재시도하지 않는다. 형식 실패가 있으면 저장된 정상 히스토리에서 다음 질문으로 계속한다. 최종 보고에서 시도 수와 실제 커밋된 턴 수를 구분한다.
- 처음 출력부터 실패하면 초기 기록이 없어 동일한 초기 상담 발화로 다음 시도를 한다. 같은 세션 ID를 유지한다.

# 평가

- 각 실제 입력에서 정보가 이미 공개 대화/요약/프로필에 있는지, 조회가 필요한지 구분한다.
- 도구 선택, arguments.reason/query/turn/state, 반환 레코드 ID, 근거와 발화로의 사용, 재조회 또는 누락을 추적한다.
- 매 요약이 정확한 전체 누적 원문을 받는지, 촉발 발화와 해석의 주체·상태 수준·겉과 속의 차이·조회 사실의 출처를 유지하는지 확인한다.
- 발화의 자연스러움·반복·정보 경계·상태 수준과 근거의 관계도 함께 본다.
- 단일 적응형 세션이며 독립 조건별 성공률이나 요약의 인과적 개선 효과로 해석하지 않는다.
