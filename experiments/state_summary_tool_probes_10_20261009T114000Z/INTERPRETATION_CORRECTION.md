# 해석 정정 · 2026-10-10

요구한 실험에서는 모델의 실행 지시를 System prompt 또는 User prompt 과제 지침에 넣고, 상담사 발화에는 실제 상담 내용만 들어가야 했다. 실험 수행자가 7~10회에 내부 기록 확인·실습 DB·함수 사용 명령을 상담사 발화로 전달했다. 이 입력으로 생긴 내담자의 압박 반응과 도구 사용을 정상적인 상담에서의 자발적 선택 또는 프레임워크 결함의 근거로 사용하지 않는다.

자연 질문 구간은 1~6회이며 성장 경험 조회는 2회째 한 번이었다. 정상 반영은 1~4회, 형식 실패는 5~6회다. 7~10회는 이 평가 집계에서 제외한다. 실제 호출과 저장 원문은 삭제하거나 고쳐 쓰지 않았다.

10회 발화의 정정은 모델에 원기록 조회와 비교를 직접 요구한 결과다. Python이 발화를 자동 정정하는 로직은 없으며, 이 사례를 자연스러운 상담에서의 자발적 정정 성능 또는 그 조건의 심리 해석 실패로 일반화하지 않는다.
