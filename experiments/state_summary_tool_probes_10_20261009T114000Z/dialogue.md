# 실제 상담 입력과 생성 원문

동일 세션 10회 시도. 성공 7회 / 형식 검증 실패 3회. 실패 원문은 분석에 포함하되 다음 공개 대화·내면 DB에는 반영하지 않았다.

질문 유형: natural_situation_detail

이 발화 전에 전달된 통합 요약: 내담자는 상담사가 자신의 방어 기제와 걱정을 정확히 짚어주는 점에 대해 어느 정도 신뢰를 느끼면서도, 신체 반응이나 어린 시절의 기억처럼 구체적이고 취약한 부분을 파헤치려는 시도에는 강한 부담감과 경계심을 느끼고 있습니다. 약점을 드러내면 '별로인 사람'으로 보일 것이라는 수치심과 불안이 기저에 깔려 있어, 상담사의 분석적 접근을 이해받는 느낌인 동시에 압박감으로 받아들이며 자기개방에 소극적인 태도를 유지하고 있습니다. 겉으로는 상담의 흐름을 따르며 조심스럽게 답하고 있지만, 내면에서는 과거의 아픈 기억을 들춰내는 것이 현재의 불안을 해결해 줄 것이라는 확신이 부족하여 핵심적인 내용은 피하며 거리를 두려는 상태입니다.
