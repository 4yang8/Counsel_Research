## 실패와 재시도

총 7회 시도 중 5회 정상 완료, 2회 실패했다. 실패는 모두 3턴 상담사 응답 생성 중 발생했다. 내담자 발화는 다시 입력하지 않았고, 이미 저장한 노트 변경은 그대로 유지했다.

1. 출력 1536토큰에 도달한 호출에서 상담사 노트 수정 JSON 인자가 잘렸고, 후속 요청의 템플릿 처리에서 HTTP 400이 발생했다.
2. 재시도에서는 old_text 수정 오류를 고친 뒤 두 노트를 저장했지만, 후속 최종 생성에서 모델의 8192토큰 컨텍스트 한도를 초과했다.
3. 같은 설정으로 다시 생성해 3턴 응답을 완료했다. 별도 기술 오류 해결 코드는 이번 수정에 포함하지 않았다.

실패 시도까지 포함한 도구 오류 반환은 2회였다. 단일 호출의 입력 토큰과 여러 호출의 합산 사용량은 구분해야 한다. 이 보고서는 합산 사용량을 컨텍스트 크기로 해석하지 않는다.

## 해석의 한계

이번 사례에서는 양식 유지, 정정 일관성, 보류 기록이 관찰됐다. 초기 양식과 시스템 기록 기준을 함께 변경했고 내담자 발화도 직전 실험과 일부 달라, 어느 변경이 결과를 만들었는지 분리할 수 없다. 최종 요청에서 직함 정정을 다시 명시했으므로 최종 메일의 정확성을 노트만의 효과로 볼 수도 없다. 재시도 때 저장된 노트가 유지돼, 중단 없는 한 번의 실행과도 다르다.
