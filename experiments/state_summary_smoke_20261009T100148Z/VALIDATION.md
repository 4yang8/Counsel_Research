# 연결 검증 결과

- 실제 Gemma 4 31B에서 2턴 모두 정상 완료됐다.
- 첫 응답의 내면상태와 실제 발화가 분리 저장됐다.
- 두 번째 턴 전에 같은 모델의 요약 담당이 직전 기록을 읽고 요약했다.
- 두 번째 메인 입력은 공개 대화·이어진 상태·요약으로 구성됐다. 이전 내면 원문은 기본 입력에 없었다.
- 두 턴 모두 원문 조회 도구는 호출하지 않았다. 이 검증은 도구 선택 성능이나 상담 발화 품질의 대조실험이 아니다.
- 선택적 조회의 실행·반환·컨텍스트 연결은 모의 모델 통합 테스트로 별도 확인했다.

원본은 `input_*.json`, `events_*.json`, `sessions/`에 보존했다.
