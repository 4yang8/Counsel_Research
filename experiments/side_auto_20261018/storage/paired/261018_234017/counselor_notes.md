## 현재 이해
- 내담자의 핵심 정서: 짜증. "내가 뭘 잘못했냐"가 반복 → 사실 확인이라기보다 감당되지 않은 짜증이 방향을 못 잡고 반복
- **핵심 전환점 1**: "잘못했다"와 "알아줬으면"을 스스로 구분
- **핵심 전환점 2**: "알아줬으면"의 구체적 내용 = "왜 그렇게 하셨어요?" (맥락을 안 상태에서 먼저 물어봐주기). "과하셨다"는 판단이 아니라, 맥락(3년 연속 1위, 매 분기 압박)을 안 상태에서 이해해줬으면 한다는 것
- **패턴**: 의미 있는 자기 명료화 → 즉시 자기비판("합리화처럼 들리겠네")으로 잡음. 자신의 이해를 신뢰하기보다 타인의 판단에 미리 내어주는 경향
- 양가감정 구조: 문제를 인정("그건 좀", "폭력처럼 보일 수 있다") → 정당화("기강이 아니라면 뭘로") → 인정과 방어 교대
- 가장 강한 순간은 HR 메일(다음 날 아침) → HR 억울함과 팀원 발언이 "같이 온다"
- 내담자가 "그건 다음에라는 거 알아요. 미안"으로 스스로 경계 유지 → 자기 조절 작동 중
- 회사 일 외의 문제 존재는 확인했으나 경계 유지 중 → 존중

## 현재 접근
- 기법: Common (명료화, 반영)
- 목적: 내담자가 방금 세운 구분("왜 그렇게 하셨어요?" = 맥락을 안 상태에서 물어봐주기)을 구체적 맥락을 포함해 반영 → "합리화"라는 자기비판이 실제 명료화와 분리되도록 돕기
- "합리화"를 부정하지도, 확정하지도 않음. 내담자의 자기비판과 실제 명료화의 관계를 가볍게 열어두기
- HR 메일 순간에 대한 경계는 짧게 존중하고 지금 열지 않음

## 진행 상황
- 내담자가 회사 일부터 다루기로 결정
- 구체적 발언 내용, 상황(공개 회의), 결과(익명 신고) 공유됨
- "무겁다" 표현을 스스로 수정 → "짜증"으로 정서 명료화
- 짜증 방향이 팀원 + 회사/HR 두 갈래로 확장 → 내담자가 스스로 "또 다른 얘기"로 구분
- **내담자가 "잘못했다"가 아니라 "알아줬으면 한다"는 욕구임을 스스로 명료화** → 전환점
- **"알아줬으면" = "왜 그렇게 하셨어요?"로 구체화** → 맥락(3년 연속 1위, 압박)을 안 상태에서 먼저 물어봐줬으면 하는 것
- "폭력처럼 보일 수 있다"도 스스로 인정 → 외부 관점 인식은 있음
- **"합리화처럼 들리겠네"로 즉시 자기비판** → 패턴 확인
- HR 메일 순간을 언급했다가 스스로 "다음에"로 보류 → 경계 존중
