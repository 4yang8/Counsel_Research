# P3a 서브에이전트 추론 예산 512 · 4턴 실험

## 결과

이번 4턴에서는 서브의 추론이 실제 문장 중간에서 종료됐지만, 조언과 최종 상담 답변은 모두 정상 완료됐고 대화의 핵심 맥락도 이어졌다. 큰 흐름 붕괴나 미완성 조언은 관찰하지 못했다. 다만 조언의 세부 방향은 제한 없는 참고 출력과 달랐고, 중요한 후반 판단이 모두 불필요했다고 결론 내릴 수는 없다.

## 조건과 범위

- 세션: `261017_164913`
- 상담사: P3a, 모델: `Qwen/Qwen3.8-27B-FP8`
- 내담자는 실험자가 직접 작성한 발화, 상담사는 실제 모델 생성. 대학원생의 교수 미팅 후 자기평가 고민을 소재로 한 단일 세션이다.
- **서브 요청에만** `thinking_token_budget: 512` 적용. 메인은 제한하지 않았다.
- temperature 0.7, top_p 0.95, max_tokens 2048.
- 서브에는 호출별 고정 seed를 넣고 참고 재생에도 같은 seed를 사용했다.
- 현재 메인·서브 프롬프트 및 상세 가이드 4개는 그대로 사용했고, 실험 전후 파일 해시가 같음을 확인했다.
- 별도 실행기에서 요청을 감싸 제한을 넣었다. 일반 UI 서버의 코드·설정이나 모델 서버 설정을 변경한 실험은 아니다.
- 세션 로그는 기존 UI와 같은 sessions/paired 경로에 저장했다. UI에서 이 세션을 이어 실행할 때에는 이 실행기의 512 제한이 자동 적용되지 않는다.

수치는 저장된 reasoning과 본문을 같은 모델 토크나이저로 다시 측정한 값이며 경계 구분자 등을 제외한다. 설정 512에 대해 표시 텍스트는 모두 511이었다. 각 추론은 각각 “the”, “ask”, “The client sees”, “if I” 등 문장 중간에서 끝났다. 단순히 자연 종료가 빨라진 사례로 해석하지 않았다.

참고 비교에서 서브 추론 텍스트는 49.4% 감소했다. 조언 본문은 다소 길어졌고, API usage의 전체 출력(추론+조언)은 약 36.2% 감소했다. 이 수치는 메인이나 입력 토큰을 포함한 전체 상담 비용 절감률이 아니다. 서버 부하와 참고 재생의 동시 실행 때문에 지연시간의 엄밀한 비교는 하지 않았다.

## 실제 대화의 연속성

1. **미팅 후 자기평가 고민.** 설명을 못한 사건, 최근 연구 부진, “무능해 보였을까”라는 걱정을 제시했다. 서브는 감정·의미 탐색과 원하는 도움 확인을 제안했고, 메인은 한 사건과 자신 전체에 대한 평가를 구분해 물었다.
2. **실수를 외면하고 싶지 않다는 요청.** 내담자는 실제 부족했던 부분을 인정하면서 전체 자기평가와 구분하고 싶다고 했다. 서브와 메인 모두 실제 설명 실패를 부정하지 않은 채 사실에서 전체 평가로 이어지는 연결을 살피는 방향을 유지했다.
3. **막힘없이 답해야 한다는 기준과 완화에 대한 걱정.** 서브는 기준 완화에 대한 예측을 경험으로 살피는 질문을 먼저 제안했고, 기준의 기능을 확인하는 선택지도 제공했다. 메인은 기능 확인을 선택했다. 이전 턴과 무관한 주제로 바뀌거나 기존 고민을 잊는 현상은 없었다.
4. **준비와 즉답을 구분하고 싶다는 요청.** 서브는 이미 나온 “더 챙겨보긴 했어요”를 활용하라고 제안했고, 메인은 그 발화를 다시 사용해 즉답하지 못했다는 사실과 전혀 준비하지 않았다는 평가를 구분했다.

**실행 확인:** 상담 4/4턴 완료, 메인 16회 호출, 서브 4회 호출. 서브와 각 턴 최종 응답은 모두 stop으로 완료됐다. 도구 실행 오류 0건. 두 노트 파일의 저장과 다음 턴에서의 참조도 이루어졌다.

## 제한 없는 참고 출력과의 차이

같은 서브 요청 4건을 한 번씩 다시 실행했다. 메시지, 모델, 생성 옵션, seed를 그대로 두고 thinking_token_budget만 제거했다. 이 참고 출력은 부모의 실제 대화나 노트를 바꾸지 않았다.

- **1턴:** 두 조건 모두 감정·의미 탐색과 방향 확인을 중심으로 삼았다. 구체적인 초점 질문은 달랐지만 핵심 접근은 유사했다.
- **2턴:** 두 조건 모두 실제 실수를 인정한 뒤, 그 사실과 전체 능력에 대한 판단 사이의 연결을 검토하라고 했다. 핵심 요청과 주의점이 유지됐다.
- **3턴:** 512에서는 기준을 낮춰본 경험·예외 검토를 먼저, 제한 없는 출력에서는 기준의 기능과 비용 검토를 먼저 제안했다. 동일한 조언은 아니다. 다만 기능 검토가 512 조언에도 있었고 메인이 이를 선택하여 실제 대화는 이어졌다.
- **4턴:** 두 조건 모두 이미 나온 준비 사실을 이용해 전체화 판단을 검토했다. 제한 없는 출력은 결과 기준을 과정 기준으로 재정의하는 방향까지 더 명시했고, 512 출력은 절대적 기준을 이상적 상태로 보고 범위를 조정하는 방향을 제시했다. 핵심 맥락은 유지됐지만 구체적인 개입 방향은 달라졌다.

## 어색함과 별도 문제

- 3턴 메인 답변에 “道理로는”이라는 한자 혼입이 한 번 있었다. 이 표현은 서브 조언에는 없었다. 메인은 제한하지 않았으며, 제한 없는 서브 참고 출력에도 “留着”, “내所能” 같은 혼입이 나타나 512에 특유한 오류라고 볼 근거는 없다.
- 기법 순서와 단계에 대해 단정하는 표현은 두 조건 모두 있었다. 예를 들어 행동 실험을 아직 이르다고 보는 판단이 양쪽 4턴 조언에 모두 나왔다. 이것은 이 실험만으로 추론 제한이 유발한 문제라고 분류하지 않았다.
- 전체적으로 질문 중심의 진행, 전문 용어와 해석을 노트에 기록하는 경향 등은 남아 있다. “응답이 정상 완료됨”과 “상담 품질 전반이 충분히 검증됨”을 동일하게 취급하지 않았다.

## 해석의 한계

- 같은 입력·seed라도 실제 추론은 잘리는 지점 이전부터 완전히 같지 않았다. 512 텍스트 전체가 참고 추론의 정확한 접두사였던 쌍은 0/4였다. 따라서 이 비교는 **원래 동일한 추론의 뒷부분만 제거한 엄밀한 인과 대조**가 아니다. 조언 차이 전부를 토큰 예산 탓으로 돌릴 수 없다.
- 제한 없는 비교는 서브 단계 재생이다. 제한 없는 부모·자식 전체 세션을 별도로 생성한 비교는 아니다.
- 메인은 제한 없이 상담 히스토리와 노트를 보고 판단했다. 메인까지 512로 제한할 때의 결과를 대표하지 않는다.
- 한 소재·한 세션의 4턴, 조건별 요청당 1회 생성이다. 더 복잡한 판단이나 다른 사례까지 안전하다고 일반화하지 않는다.

## 확인한 범위의 판단

서브 512는 실제로 작동했으며, 이번 4턴에서는 큰 연속성 문제 없이 사용할 수 있었다. 세부 조언의 변화와 일부 어색한 표현은 있어 “품질 손실이 전혀 없다”고 말할 수는 없다. 일반 UI에 영구 적용하거나 메인에도 같은 한도를 적용하는 결론은 이번 실험에서 내리지 않았다.
