# P2: 내담자 노트와 상담사 생각 노트

P1을 유지하고 상담사 버전 선택에 P2를 추가합니다. 새 세션에서 P2를 선택하세요.

- `paired/<session_id>/notes.md`: 대화에서 확인된 내담자 정보.
- `paired/<session_id>/counselor_notes.md`: 상담사의 현재 이해, 미확인 사항, 이어갈 방향과 계획.

매 상담사 턴 시작 시 두 파일을 읽어 기본 컨텍스트 하단에 원문을 넣습니다. 같은 턴의 도구 후속 호출에서는 이 기본 입력을 바꾸지 않으며, 수정 결과는 `role: tool`로 전달합니다. 다음 상담사 턴에는 최신 파일을 읽습니다. 같은 턴의 reasoning은 보존하고 이전 턴의 raw reasoning은 다시 넣지 않습니다.

`update_notes(target, edits)` 하나로 파일을 선택합니다. `target`은 `client` 또는 `counselor`이며 경로를 직접 받지 않습니다. 실제 수정은 P1의 정확한 문자열 교체·추가·삭제, 파일별 revision 검사, 원자적 저장 로직을 재사용합니다. 후속 생성 실패·중단 시 이미 저장한 변경은 유지됩니다.

시스템 지침은 내담자 노트 검토·필요시 수정 → 상담사 생각 노트 검토·필요시 갱신 → 상담 발화 순서를 안내합니다. 런타임이 두 도구 호출이나 순서를 강제하지는 않습니다. 완료되거나 불필요해진 계획은 제거·수정하고 다음 상담에 필요한 결론은 짧게 남기도록 지시합니다. 갱신 여부와 내용은 같은 상담사 모델이 판단하며 별도 요약 모델은 없습니다.

UI는 발화의 생성 과정 안에서 두 노트 원문과 각각의 추가·삭제 내역을 표시합니다. reasoning 스트리밍, raw context, workflow와 저장 세션 복원은 기존 공통 UI를 사용합니다. 실제 모델의 호출 선택·노트 품질은 별도 실험으로 확인해야 합니다.
