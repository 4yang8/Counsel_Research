# Reasoning 켜기/끄기 · 고정 내담자 입력 4턴

- 질문: reasoning이 도구 선택·노트 정확성·상담 진행과 비용에 어떤 차이를 만드는가?
- 원본 P3a 프롬프트·상세 가이드·도구 유지. 메인과 자문 모두 같은 Qwen 모델 사용.
- 조건별 새 세션, 같은 시작 발화·빈 양식 노트·내담자 입력 4개. reasoning 외 설정 동일.
- 이전 공개 발화와 노트는 각 조건에서 누적. 따라서 2턴부터 모델 입력은 경로에 따라 달라짐.
- 순서: 1·3턴 on→off, 2·4턴 off→on. 서버 캐시·부하에 따른 시간 차이는 완전히 통제 못 함.
- reasoning budget 없음, max_tokens 8192, seed 20261019, temperature .7, top_p .95.
- 각 조건 1세션. 메인·자문 각각의 효과 분리, 자유로운 내담자의 후속 반응, 통계적 우위는 검증하지 않음.
- 원본 코드·프롬프트는 수정하지 않음. 실제 요청·응답·reasoning·노트·오류를 보존.
