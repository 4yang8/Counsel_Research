# 장문·문맥 의존·동일 N 선별 결과

## 비교 범위

후보30턴, 비공개 기록 평균1078자, 공개 문맥이 필요한 질문12개, 두 반복이다. N=1/2/3을 양쪽에 똑같이 알려주고 정확히 N개만 선택한다. 정답이 없는 질문은 없다. 첫 반복은 후보 시간순, 두 번째는 후보만 고정 seed로 섞었으며 공개 대화의 시간 순서는 유지했다. 모든 실제 요청·응답은 이 실행 폴더에 저장했다.

정답은 대상 발화를 만들 당시 원본 ID다. 나중의 회고나 유사한 다른 발화는 답을 설명할 수 있어도 해당 원본 대신 선택하면 오답이다. 이 제한은 양쪽 지침에 명시했다. 작성자 지정 정답이고 독립 검증은 없으며, 임상적 타당성이나 실제 후속 응답 품질을 측정한 실험은 아니다.

## 해석 제한

- 두 방법의 반환 수는 동일하다. 따라서 이번 결과를 이전의 RAG 고정3개/LLM 최대3개 결과와 그대로 비교해서는 안 된다.
- 기록 제목 제거, 같은 인물로 사건 변형, 직전 문맥 추가, 원본 선별 지침 및 N 통제가 함께 바뀌었다. 단일 난도 요인의 인과 실험은 아니다.
- 난도를 높이도록 설계했지만 모델이 계속 모두 맞히면 해당 조건에서 원본 선별이 안정적이라는 관측까지만 말한다. 오류가 날 때까지 문항을 바꾸지 않았다.
- 두 번째 반복은 seed와 후보 순서가 함께 바뀐다. 순서 효과를 별도로 추정할 수 없다.
- 검색어 생성 실패/비교 대상 누락과 임베딩 순위 실패를 구분해야 한다. RAG 자체 전체를 단일 오류 원인으로 취급하지 않는다.
- 한 인공 내담자와 두 반복은 독립된 다수 상담 사례가 아니다. 신뢰구간·통계적 유의성·일반적 우열을 주장하지 않는다.

## 원문 확인 후 해석

- RAG는 전체24회 중13회 완전 일치했다. 10회는 정해진N개를 반환했지만 다른 원본을 포함했고, 1회는 검색어 생성이4096 출력 토큰을 모두 추론에 사용하고 최종 JSON 없이 종료돼 검색 자체가 실행되지 않았다. 이를 임베딩 검색의 오순위와 분리해야 한다.
- LLM 원본 선별은24/24회 완전 일치했다. 시간순12회와 후보 순서를 섞은12회 모두 일치했다. 이번 자료에서도 해당 LLM의 원본 선별 한계는 관찰하지 못했다.
- RAG의 성공적으로 끝난 오선택10개를 원래 검색어 그대로 전체30개 순위로 다시 확인했다. 10개 모두 원래Top-N이 재현됐다. 정답은 아예 없는 것이 아니라 반환 경계 아래로 밀린 경우가 많았다. 예를 들어 두 순간의 같은 동의를 비교한 질문에서 최초 동의3은3위이고 N=2라 빠졌다.
- 세 번의 보류/시도를 비교한 `context_disclosure_chain`에서는 검색어에 중단 신호 표현도 포함됐지만 원본23이 두 반복 모두4위였다. Top-3에 대신 들어온8은 아버지의 비난 이야기를 보류한 다른 사건이다. 이 사례는 검색어 생성 실패만으로 설명할 수 없고, 긴 기록들의 단일 임베딩 유사도 순위가 필요한 서로 다른 세 시점을 모두 상위에 놓지 못한 관측이다.
- `context_same_friend` 첫 반복은 검색어가 친구의 부탁과 생각해보겠다는 대답으로 축약되어 재초대와의 대비가 약해졌다. 원본10 대신 후속 거절25를 추가하고 다른 원본29를3위에 두었다. 검색어의 비교 대상 보존과 원본/후일 회고의 순위 문제를 함께 점검해야 한다.

[전체 순위 사후 진단](ranking_diagnosis.json). 이 진단은 검색어를 개선하거나 기존 점수를 바꾸지 않았으며 본 실행에 합산하지 않았다.

이번에는 반환 수의 차이를 제거했으므로 앞선 최대3개/고정3개 비교보다 원본 선택의 차이를 직접 볼 수 있다. 다만 정답 개수를 미리 알려주었고 원본 ID를 정확히 찾는 작성자 정의 과제라는 제한이 있다. 후속 발화에서는 회고 기록만으로도 타당하게 답할 가능성이 있으므로 이 점수만으로 상담 반응이 왜곡됐다고 결론내릴 수 없다.
