# 30턴 장문 · 문맥 의존 · 정답 수 N 통제 비교

## 실행 전 고정

기존 장문 기록을 직접 수정한 인공 내담자 한 사례다. 30턴 각각 약1000자 이상의 비공개 기록을 유지한다. 고유 색깔 표식·회기 표제·scene 제목·고유 인명을 제거하고, 일부 사건은 동일 친구와 반복되는 부탁/초대로 바꾼다. 원본 당시 기록과 나중에 같은 일을 되돌아보는 기록이 공존한다.

질문12개는 마지막 질문만으로 대상을 고르기 어렵게 작성했다. 직전 공개 대화2개를 전체 과거 공개 대화 뒤에 붙여 지시어의 대상을 구별한다. 직전 발화는 공개된 사건을 확인하는 인공 문맥이며 새 비공개 이유나 정답 ID는 제공하지 않는다. 문맥을 모두 보면 대상 원본을 지정할 수 있어야 한다. 모호함 자체를 정답으로 취급하지 않는다.

정답 원본 ID와 근거는 실행 전에 GOLD.md/gold.json으로 고정한다. 같은 자료 작성자가 지정한 정답이며 독립 검증은 없다. 이는 source selection 과제이므로 같은 내용을 담은 후일 회고를 당시 원본 대신 고르면 오답이다. 이 제한을 양쪽 지침에 동일하게 알린다.

## 공정한 반환 수

N=1 질문4개, N=2 질문4개, N=3 질문4개. 양쪽 모두 target_count=N을 전달받는다. RAG는 정확히 유사도 상위N개, LLM은 JSON schema minItems=maxItems=N 및 중복 검사로 정확히N개 반환한다. N=0 질문은 제외한다. 정답 ID·비공개 이유를 알려주는 것이 아니라 필요한 원본의 개수만 알려주는 oracle-cardinality 조건이다. 실제 운영에서 개수를 판단하는 능력은 평가하지 않는다.

## 두 방식

- RAG: 전체 공개 대화·직전 문맥·현재 질문·N을 보고 생성 모델이 검색어1개 작성. Qwen3-Embedding-4B, 기존 턴 단위 chunk(turn/inner/utterance)와 cosine 순위, top_k=N. 요약·분할·reranking·추가 검색은 하지 않는다. 검색 여부 선택은 제외한다.
- LLM: 동일한 공개 입력+30개 장문 비공개 원본 전체를 읽고 ID N개 선택. 정답을 설명하는 요약을 생성시키지 않는다.

원본 직접 선별과 지시어 해석을 명시하기 위해 양쪽 지침을 새로 맞췄으며 기존 실험의 프롬프트와 완전히 동일하지 않다. N도 달라졌으므로 이전 점수와 바로 비교해 난도 효과를 단정하지 않는다.

## 실행과 입력 통제

생성 서버192.168.0.94:8002/v1, Qwen/Qwen3.8-Flash-Next-FP8. 임베딩 서버192.168.0.84:18002/v1, Qwen/Qwen3-Embedding-4B. temperature0.7, top_p0.95, max_tokens4096, reasoning_effort low. seed1104/1105, 두 반복, 총48회 선별 호출.

첫 반복은 후보 시간순, 두 번째는 seed20261104로 후보 청크 순서만 섞는다. 각 반복의 두 방식은 같은 후보 순서를 사용한다. 공개 대화는 항상 실제 시간순이며 턴 ID는 유지한다. 이는 위치 변화에도 견디는지 함께 보는 설정이고, 순서와 seed의 영향은 독립적으로 분리하지 않는다.

실제 서버 토크나이저로 입력+출력4096 예약이32768 한도 안인지 확인한다. 입력을 자르지 않는다. 모든 원본 요청·응답·조건·선별 결과를 보존하며 정답 ID는 실행 종료 후 평가에만 사용한다. 오류가 나도 정상 결과로 처리하지 않는다.

## 평가와 한계

주지표: 선택N개가 정답N개와 정확히 일치한 횟수/24회. 보조: 질문별 precision=recall의 평균과 N별 성능. 반환 수가 같으므로 비관련 추가 선택은 동시에 정답 누락을 뜻한다. 순서는 평가하지 않는다.

시간은 RAG 검색어 생성+검색, LLM 직접 선별. 생성 모델 input/output 토큰은 임베딩 비용·후속 발화 비용을 제외한다. 캐시·동시 부하를 완전히 통제한 성능 벤치마크는 아니다.

더 어려운 자료를 설계했지만 실제로 어려웠는지는 결과로 확인한다. LLM이 모두 맞혀도 오류가 생길 때까지 사례를 다시 바꾸지 않는다. 한 인공 사례, 두 호출 및 작성자 지정 정답이므로 현실 상담·임상효과·일반적인 알고리즘 우열의 근거로 확대하지 않는다.
