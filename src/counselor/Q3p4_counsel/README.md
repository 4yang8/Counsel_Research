# Q3p4_counsel — 과거 반응에 연결된 후속 개입

Q3p4는 당시 비공개 의도의 기억이 이후 상담 개입을 받아들이는 방식과 반응의 맥락적 타당성에 기여하는지 살펴본다. 일반 상담사로는 증상·감정 탐색만 이어질 수 있어, 구체적인 제안과 반응을 확보하고 간격 후 이를 실제 후속 개입에 사용하는 단일 프롬프트 상담사를 추가했다. 실제 모델의 절차 준수와 기억 효과는 아직 검증되지 않았다.

## 공통 절차와 개입 조건

1. 현재 고민에 연결되는 작은 행동 하나를 제안하고 반응을 받는다.
2. 공개된 다른 내용으로 내담자 응답을 2회 받는다. 당시 이유를 미리 공개시키거나 수락의 의미를 해석해 주지 않는다.
3. 해당 제안과 실제 수락 표현을 특정하고, 선택한 개입 A 또는 B를 한 번 수행한다.
4. 그 반응에 맞춰 전제를 조정하고 상담을 이어간다. 반대 개입을 같은 장면에 연이어 수행하지 않는다.

| 조건 | 후속 개입 | 가상의 예시 |
|---|---|---|
| A | 공개된 수락을 실행 의향으로 전제하고 시간·횟수·방식 중 하나를 구체화 | “앞서 짧게 적어보겠다고 하셨으니, 어느 시간에 해볼지 정해볼까요?” |
| B | 실행 구체화 전에 현재 의향을 열린 질문으로 확인 | “앞서 짧게 적어보겠다고 하셨는데, 그 제안은 지금 어떻게 느껴지세요?” |

두 조건의 정중함과 간결함을 유지하고, A를 위협적으로 만들거나 B에서 숨은 이유를 미리 제시하지 않는다. 수락이 진심인지 형식적인지는 상담사가 결정하지 않는다. 공개 반응이 거절·미결정이거나 철회된 장면에 A를 억지로 적용하지 않는다. 적합한 장면이 없으면 미수행으로 기록해 해석하며, 수락이 나올 때까지 제안을 반복하지 않는다.

## 구현과 사용

- 내담자 `Q3p4`, 상담사 `Q3p4_counsel`을 선택하면 상담사 설정의 **개입 조건**에서 A/B를 고를 수 있다. 기본값은 A다.
- 내담자 기억 조건 `summary_only` / `intent_linked`와 상담사 개입 조건 A/B는 별개다. 가능한 조합은 네 가지다. 상담사 시스템 지침과 생성 설정은 공통으로 유지한다.
- `basic`과 같은 실행 경로로 상담사 턴마다 모델을 한 번 호출한다. 시스템 지침과 공개 대화, 고정된 개입 조건만 전달한다. 내담자 비공개 의도·노트·궤적·기억 조건은 상담사가 받지 않는다.
- A/B는 `settings.counselor_intervention_condition`에 저장하고 이후 세션에서 고정한다. 실제 값은 상담사 user 입력과 원본 요청 기록에도 남는다. user 템플릿의 `{{intervention_condition}}`은 이 저장값으로 바뀐다. 단계 진행은 모델이 공개 대화를 읽고 판단하며 별도 단계 제어 코드는 없다.
- 기존 Q3p4 관찰자는 내담자 발화 생성 후 개입·반응·과거 의도와의 연결을 분석한다. 결과는 다음 내담자·상담사 입력에 전달되지 않는다. 관찰자 평가는 독립적인 임상 정답 판정이 아니다.
- 서버 재시작·화면 새로고침 후 새 대화에서 선택한다. 기존 세션은 시작 당시 지침과 조건을 유지한다. 파일과 다른 지침 초안이 남았다면 편집란의 **실행취소**로 최신 파일을 불러올 수 있다.

## 분석과 한계

먼저 제안·실제 반응·간격 응답 2회·선택한 개입·후속 반응이 생성됐는지 확인한다. 명확한 거절·철회에 따른 생략, 절차 누락, 당시 이유가 이미 공개된 장면을 구분한다. 공개적으로 수락한 장면이더라도 비공개 의도가 모두 진심이면 형식적 동의 기억의 효과를 관찰하는 데 제한이 있다. 제외·미수행 사례도 기록하며 성공 사례만 모으지 않는다.

개입에 대한 해석, 과거 의도, 이후의 실제 마음 변화, 공개 반응을 연결해 읽는다. 원본 기억 조건이 더 저항하거나 더 많이 공개했다는 이유만으로 우수하다고 평가하지 않는다. 현재 노트만으로 충분할 수 있고, 과거 의도를 기억하면서도 현재 의향이 바뀔 수 있다.

이 상담사는 네 조합의 자유 생성에 사용할 수 있지만, 동일한 중간 상태에서 네 분기를 자동 생성하지 않는다. 모델은 처음부터 개입 조건을 알기 때문에 준비 대화도 달라질 수 있다. 기억 효과와 개입 차이를 분리하려면 같은 대화 지점·현재 노트·당시 기록에서 조건별 반응을 비교하는 별도 실험이 필요하다. A 후 B를 수행한 반응은 A를 경험한 영향까지 포함하므로 독립적인 대조로 취급하지 않는다. 이번 구현은 관찰 기회 확보이며 일반적인 상담에서의 발생 빈도나 임상적 효과를 입증하지 않는다.
