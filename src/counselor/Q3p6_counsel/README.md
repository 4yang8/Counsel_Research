# Q3p6_counsel 설계 이유

Q3p6는 같은 과거에서 기억 조건 A/B의 반응을 비교한다. 상담사는 공개 대화만 사용하며 비공개 내면 기록을 받지 않는다.

## 현재 설계 (revision 3)

- `system.md`와 `user.md`: 초반 1~2회 탐색 뒤 공개된 고민에 연결된 작은 행동을 제안한다. 수락·거절·보류는 강제하지 않는다. 이후 다른 관련 경험을 살펴 같은 탐색을 반복하지 않도록 한다. 안전 문제와 필요한 기초 정보가 우선이다.
- `interventions.md`: 지정한 시점마다 공개 이력에서 자연스럽게 재연결할 수 있는 발화와 후속 질문을 준비한다. 수락뿐 아니라 망설임·거절·자기개방 등도 대상이며, 수락 여부로 분기를 막지 않는다. 가능한 한 현재 턴보다 앞선 발화를 선택하고 당시 발화를 정확히 인용한다.
- 기본 I1은 대상 발화와 이어지는 현재 반응을 묻는다. 선택 설정인 I2는 같은 주제의 부담·선택권·원하는 속도를 확인한다. 숨은 이유를 추정하거나 특정 대답을 정답으로 유도하지 않는다.

실행기는 후속 질문을 한 번 저장하고 A/B와 반복에 같은 문장을 전달한다. 연구 관련성은 `potential/weak`, 대화 흐름과의 연결은 `natural/forced`로 구분한다. 기본 정책은 부자연스러운 재연결을 사유와 함께 건너뛰고, 수락 여부로는 막지 않는다. 이는 공개 이력에 대한 LLM의 참고 판단이며 실제 기억 효과나 연구 적합성 판정은 아니다.

## 변경 배경

최초 설계는 상담사가 ‘적절할 때’ 제안하도록 하면서 분기에는 ‘명확한 수락’을 필수로 요구했다. 실제 첫 실행은 4~8턴 모두 미수행이었다. revision 2는 제안 기회를 구체화하고 분기 실행과 사례 적합성 검토를 분리한다. 과거 실험의 개입 원문과 판정은 바꾸지 않는다.

[실험 사용 방법과 해석 범위](../../client/Q3p6/README.md)


revision 3에서는 정해진 1·3·5턴 간격으로 같은 질문을 강제하지 않는다. 같은 시점의 A/B에는 같은 질문을 주되 다른 시점에는 맥락에 맞는 질문을 허용한다. 변화·개선을 기대하는 질문 반복을 피하고 현재 선택·의향을 열어 묻는다. 이 상담사 지침은 독립 A/C 경로에서도 동일하게 사용하되 각 경로의 공개 대화만 받는다.


revision 4의 `당시 의도 확인 · 고정 재질문` 모드는 `intent_target.md`로 공개 발화 대상만 선택한다. 질문은 UI에 저장한 `{target_quote}` 템플릿을 코드로 한 번 렌더링해 A/B의 분기 첫 질문에 공유한다. 공통 경로·독립 C·분기 2턴째 이후에는 기존 상담사 지침을 사용한다. 이 진단에서는 자연스러운 재연결 판정으로 분기를 건너뛰지 않는다.


revision 5: 당시 의도 확인 모드에서 C를 포함하면 독립 A/C에도 자기 과거 발화를 대상으로 같은 질문 템플릿을 적용한다. 각 경로의 본 대화는 유지하고 별도 복사본에서만 재질문한다. A 경로 반복 1은 기존 A/B의 A 결과를 재사용한다. A/C의 실제 인용문과 이력은 다르므로 같은 입력의 대조로 해석하지 않는다.
