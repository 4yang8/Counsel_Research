# P3q

내담자가 앞서 한 말을 되짚어 당시 마음이나 뜻을 묻는 것을 기본 방식으로 하는 상담사다. 언제 무엇을 되물을지는 상담사가 공개 대화를 보고 스스로 정한다. 정해진 턴 일정은 없다.

## 목적

속마음과 겉말이 달랐던 발화를 나중에 되물었을 때, 내담자의 답이 당시 내면 기록과 맞는지를 보려는 상담 상황을 만든다. 상담사는 공개 대화만 읽으므로 어느 발화에 숨김이 있었는지 모른다. 짧은 답, 망설임, 화제 전환 같은 겉의 흔적을 보고 되묻는다.

## 입력과 출력

- **입력:** 시스템 지침(`system.md`)과 턴 번호를 붙인 공개 대화(`user.md`)뿐이다. 내담자 프로필, 내면 기록, 실험 조건은 받지 않는다.
- **출력:** 한 번의 호출로 JSON 하나를 받는다.

```json
{"utterance": "아까 '괜찮다'고 하셨는데, 그 말을 하실 때 마음은 어떠셨어요?",
 "revisit": {"is_revisit": true, "client_turn": 3, "quote": "괜찮아요"}}
```

- `utterance`만 공개 대화에 들어간다.
- `revisit`은 분석용 표시다. 직전 내담자 발화보다 앞선 턴의 내담자 발화를 짚어 물을 때만 `is_revisit`이 true다.

## 되짚기 표시의 저장

실행부(`runtime.py`)가 표시를 정리해 상담사 쪽에만 저장한다.

| 항목 | 뜻 |
|---|---|
| `counselor_turn` | 이 상담사 발화의 턴 번호 |
| `is_revisit` | 되짚기 여부 |
| `client_turn` | 짚은 내담자 발화의 턴 번호. 되짚기가 아니거나 번호가 올바르지 않으면 null |
| `quote` | 상담사가 적은 인용 표현 |
| `quote_found` | 인용이 그 턴의 내담자 발화 원문에 그대로 있는지 (공백 무시) |
| `valid` | 가리킨 턴이 1 이상이고 직전 내담자 턴보다 앞인지 |
| `raw` | 모델이 낸 표시 원본 |

- 저장 위치는 `session.json`의 `counselor_checkpoint.revisits`(발화 순서대로 전체)다. 대량생성에서는 각 상담사 단계(`steps[]`)의 `revisit`에도 같은 내용이 들어간다.
- 표시가 올바르지 않아도 발화 생성은 실패시키지 않는다. `valid: false`로 남기고 분석에서 제외한다. 턴 번호를 추정해 고치지 않는다.
- 표시는 공개 대화(`public_dialogue`)에 들어가지 않으므로 내담자 입력에 전달되지 않는다.

## 사용

- 대량생성 화면(`/batch`)의 상담사 버전에서 선택한다. 분기 방식(`Q3compare_memory`)에서는 기본값이다. 두 조건을 따로 생성하는 기존 방식에서도 쓸 수 있다.
- 실험 화면의 상담사 버전 목록에도 나온다.

## 지침 변경 기록

### 2026-11-11: 되짚는 질문의 형태와 후보 확인 절차

- **이유:** `batch_2a8d1de4…`에서 분기 뒤 상담사 발화 480개 중 되짚기가 29개(6%)였고, 질문 다수가 "그 말이 지금 보기에 어떤가", "같은 결인가 다른 결인가"처럼 당시 마음이 아니라 현재의 의미를 물었다. 이런 질문은 당시 내면 기록 없이도 답할 수 있다. reasoning을 보면 되짚을 후보를 찾지 않고 직전 발화에만 반응한 턴도 있었다.
- **변경:**
  - 매번 발화 전에 공개 대화를 훑어 아직 되짚지 않은 발화가 있는지 확인하게 함
  - 되짚는 질문은 그 말을 하던 당시의 마음, 말하려던 것, 하려다 만 말을 묻게 함
  - 현재 의미를 묻는 질문, 선택지를 주는 질문, 해석을 붙여 확인을 구하는 질문을 피하게 함
- **바꾸지 않은 것:** 되짚는 시점은 여전히 상담사가 정한다. 턴 일정, 출력 형식, 표시 저장 방식은 그대로다.

## 한계

- 되짚는 빈도와 대상은 통제하지 않는다. 숨김이 있던 턴을 되묻는 경우가 얼마나 나오는지는 생성 결과로 확인해야 한다.
- 표시는 상담사 모델이 스스로 적은 것이다. 발화가 실제로 그 턴을 가리키는지는 `quote_found`로 일부만 확인된다.

## 검증

`PYTHONPATH=src:tests python3 -m unittest test_compare_branch -q` — 표시 정리 규칙, 상담사 입력에 비공개 정보가 없는지, 표시가 공개 대화에 들어가지 않는지를 확인한다.
