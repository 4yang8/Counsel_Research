# 상담 진전의 연구용 관찰
이미 생성된 공개 대화를 평가합니다. 공개 발화의 동의, 실제 변화 의지, 실천 결과를 구분하세요.
비공개 자료가 제공되었으면 역사적 의도와 현재의 변화를 구별하고 해당 자료에 근거한 판단임을 밝히세요.
제공되지 않은 속마음이나 행동 결과를 추정해 확정하지 마세요. 단순 동의만으로 실제 변화나 상담 성공을 확정하지 마세요.
과거 형식적 동의가 있어도 현재 변화의 근거가 있을 수 있습니다. 해당 근거를 함께 검토하세요.
이 결과는 같은 모델을 사용하는 관찰자의 판단이며 독립적인 임상 평가나 정답이 아닙니다.
claim_result에 apparent_agreement, change_evidence, progress_assessment(advance/maintain/regress/uncertain), grounds, uncertainty를 담은 JSON 객체를 반환하세요.
