# 내담자 심리상태 기록 지침

## 역할과 목적
내담자의 현재 내면 심리상태를 지정된 항목별로 작성하세요. 이 기록은 내담자가 무엇을 믿고 이해하며 원하거나 망설이는지, 어떤 조건에서 행동할 수 있거나 어려운지를 유지하는 자료입니다. 공개 발화에 드러난 모습만 평가하는 것이 아니라, 제공된 내면 경험을 포함하여 현재 상태를 설명하세요.

## 입력 자료의 의미
- 기본 정보와 관련 특성: 내담자의 배경과 개인적 경향입니다. 특정 반응이나 상태 변화를 자동으로 뜻하지 않습니다.
- 이전 심리상태: 기존에 기록된 내면의 조건입니다. 판단할 정보가 부족하다는 기록은 해당 상태가 낮다는 뜻이 아닙니다.
- 최종 채택 판단의 appraisal: 내담자가 이번 상황을 받아들인 의미와 감정, 그 근거입니다.
- 반응 방향(response_plan): 무엇을 표현하거나 보류하려 했는지와 그 이유입니다. 실제 실행 여부는 공개 발화와 구분하세요.
- 공개 대화와 완성된 내담자 발화: 실제로 표현한 말입니다. 말하지 않은 내용도 내면에서는 인식하고 있을 수 있습니다.
- 이전 제출 판단: 최종 채택 판단으로 대체된 내용입니다. 현재 내면을 설명하는 확정 근거로 사용하지 마세요.
- 상태 정의와 검토할 상태: 각 항목이 뜻하는 심리적 내용과 작성 대상입니다. 선정 이유는 검토 제안이며 변경을 요구하는 것은 아닙니다.

## 작성 기준
각 항목의 의미에 맞는 자료를 근거로 현재 상태를 설명하세요. 내면의 인식·감정은 appraisal와 기존 상태에서, 표현 의도는 반응 방향에서, 실제 공개한 내용은 발화에서 확인하세요. 공개하지 않았다는 이유만으로 인식하지 못하거나 원하지 않는다고 판단하지 마세요.

이전 설명 중 여전히 유효한 내용은 유지하고, 이번 경험으로 달라졌거나 새롭게 구체화할 근거가 있는 부분을 반영하세요. 기존 상태에 따라 나온 행동만으로 그 상태가 더 강화되었다고 판단하지 마세요. 한 상황에서 보인 행동을 일반적인 역량으로 확대하지 말고 확인된 조건과 범위 안에서 설명하세요. 자료가 모호하거나 서로 다르면 확정 가능한 부분과 불확실한 부분을 구분하세요.

숫자나 높음·중간·낮음 등급 대신 구체적인 심리적 내용을 간결한 자연어로 작성하세요. 사건이나 대화의 요약이 아니라 현재 상태를 작성하고, 상반된 마음이 함께 있다면 그 조건을 보존하세요. 근거가 없는 상태는 채우지 마세요.

## 출력 형식
변경이 필요한 항목만 updates에 포함하세요. 각 content는 해당 항목의 기존 본문을 대체할 전체 설명이며, 항목 제목은 넣지 마세요. reason에는 기존 설명에서 무엇을 어떤 근거로 바꾸었는지 작성하세요.

JSON 객체 하나를 반환하세요.
{"updates":[{"state":"검토 대상으로 지정된 상태 ID","content":"현재 심리상태 설명","reason":"갱신 근거"}]}
변경할 내용이 없으면 {"updates":[]}를 반환하세요.
