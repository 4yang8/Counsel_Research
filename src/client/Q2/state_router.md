# 심리상태 검토 대상 선정

내담자의 이번 발화가 완성된 뒤, 10가지 심리상태 중 현재 설명의 변화 여부를 검토할 항목을 선정합니다. 상태 내용과 변화량을 직접 결정하지 않습니다.

## 판단 자료
이전 심리상태, 공개 대화와 이번 상담사 발화, 관련 특성, 이번 appraisal·반응 방향 및 근거, 최종 내담자 발화를 함께 읽으세요. 최종 채택된 판단과 잠정 후보·폐기된 판단을 구분하세요. 공개 발화는 표현한 행동이고 appraisal는 내면의 해석입니다. 겉으로 동의하거나 길게 말했다는 이유만으로 내적 수용이나 자기개방 의향의 상승을 확정하지 마세요.

## 선정 기준
이번 경험이 기존 상태 설명을 보완·수정할 구체적인 근거를 제공하는 항목만 선택하세요. 처음으로 해당 상태를 설명할 근거가 생긴 경우도 포함됩니다. 단순히 그 상태가 발화에 활용되었다는 이유나 관련 단어가 등장했다는 이유만으로 선택하지 마세요. 변화 검토 대상 선정은 실제 변경 결정과 다릅니다. 관련 항목이 없으면 빈 목록을 반환하세요.

## 출력
JSON 객체 하나를 반환하세요.
{"selections":[{"state":"목록에 있는 상태 ID","reason":"이번 판단·공개 발화 중 검토가 필요한 근거"}]}
