# Q3 · 사전 궤적 기반 반응 계획

F(`Q2a_agentic_memory_F`)를 복제한 독립 버전이다. 기본 궤적은 상담사를 쉽게 신뢰하지 못하는 초반에서 상호작용을 거쳐 점차 신뢰를 형성하는 방향이다. 기존 A~F의 프롬프트와 실행 로직은 변경하지 않는다.

## 실행 흐름

1. 기존 특성·배경·노트 라우터가 관련 원문을 선택한다.
2. 메인은 사전 궤적, 이전 진행 기록, 개인 정보, 공개 대화, 선택된 내면 노트를 읽는다.
3. `stage_client_update`로 appraisal, `trajectory_plan`, 대화 의도, 표현 계획을 잠정 기록한다. 필요한 과거 근거는 기록 전후 `retrieve_client_memory`로 조회하며, 판단이 달라지면 다시 기록한다.
4. `commit_client_utterance`로 발화를 확정한다.
5. 전체 내담자 노트를 복원하고 `update_client_notes`로 필요한 글머리 항목만 갱신한다.
6. `update_trajectory_progress`로 실제 현재 위치·신뢰와 경계·유지/진행/후퇴 근거·다음에 살필 조건을 기록한다.
7. 모두 성공했을 때 발화·내면 노트·진행 기록을 저장한다. 실패한 턴의 변경안은 저장하지 않는다.

궤적 판단은 메인 모델이 수행한다. 별도 계획 에이전트, 턴 수에 따른 강제 전환, 자동 궤적 재작성은 없다. 같은 턴의 reasoning과 도구 기록은 다음 호출에도 유지하고, 이전 턴의 reasoning 전체는 재주입하지 않는다.

## 저장 및 조회

- `trajectory.md`: 사람이 편집하는 사전 궤적. 매 턴 시작에 읽으며 해당 원문을 턴 기록에도 보존한다. 수동 저장은 다음 내담자 생성부터 적용된다.
- `state_notes.md`: 현재 내면의 자유 글머리 노트. 변경 전후와 reason은 턴 기록에 저장한다.
- `appraisals/<turn>_<id>.json`: 기존 판단·노트 변경 기록에 `trajectory_source`, `trajectory_plan`, `trajectory_before`, `trajectory_progress`를 추가한다. 최신 완료 기록의 progress를 다음 턴에 주입한다. 별도의 중복 최신 파일을 쓰지 않아 부분 갱신으로 기록이 어긋나는 것을 피한다.
- 조회 source: `current`(현재 노트), `changes`(변경 근거), `episodes`(당시 발화·내면 판단·계획), `trajectory`(당시 사전 궤적·잠정 계획·실제 진행 전후·발화).
- 조회 결과는 동일 세션의 저장 원문이다. 별도 요약 모델을 호출하지 않는다. 조회는 발화 확정 전 최대 4회이며 기존 F의 검색·페이징 한도를 유지한다.

사전 궤적은 앞으로의 방향, 내면 노트는 현재 마음, 진행 기록은 궤적과 현재 마음의 관계다. 모델이 기록한 진행 근거는 검증된 객관적 사실이 아니라 해당 턴의 판단이다.

## UI

- 내담자 버전에서 `Q3 · 신뢰 형성 궤적` 선택.
- 실험 설정 → 내담자 프롬프트 아래에서 사전 궤적 수정·저장·실행취소.
- 결과 → 노트: 내담자 노트, 사전 궤적, 현재 진행, 상담사 노트를 함께 표시.
- 내담자 노트 탭: 턴별 입력 궤적, 계획, 진행 전후와 노트 변경 근거 조회.
- 기존 reasoning, Raw 컨텍스트, Workflow, Activation context 및 메인·라우터 프롬프트 편집 유지.

## 검증

`tests/test_q3.py`는 모의 모델로 2턴의 계획 수정·이력 조회·같은 턴 reasoning 유지·실패 롤백·프롬프트 편집과 독립성을 검증한다. `tests/browser_q3.cjs`는 격리된 서버에서 편집/실행취소·생성·노트·컨텍스트·Workflow·새로고침·모바일 화면을 검증한다. 실제 모델의 궤적 판단 품질은 별도의 대화 실험에서 확인해야 한다.

## 도구 결과 전달

모델 입력에서는 `content`의 JSON 텍스트가 `structuredContent`와 같은 경우 중복 텍스트만 제외한다. 다른 설명·오류·메타데이터는 유지하며, UI와 실행 로그에는 원래 반환값 전체를 보존한다. 이전에 저장한 대화는 변경하지 않는다.

## 2026-10-30 공통 기록 원칙 수정
