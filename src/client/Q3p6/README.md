# Q3p6: 같은 과거에서 내면 기록의 추가 효과 비교

현재 상태·이유 포함 노트에 **과거 발화 당시 확정 내면 기록을 추가했을 때** 상담 개입에 대한 반응이 달라지는지 살펴보는 자동 분기 실험이다. Q3의 발화·내면·노트 생성 구조를 사용한다.

## 현재 버전: revision 5

A/B는 같은 공통 과거에서 원본 기록의 추가 효과를 비교한다. C는 명시적 내면 생성·기록 없이 **독립 경로**로 생성한다. 이전 실험은 그대로 보존하며, 수정된 설계는 새 실험에 적용된다.

기본 분기는 현재 맥락에서 자연스럽게 이전 주제를 다시 다룰 수 있는 시점에 수행한다. 수락은 필요하지 않다. 부자연스러운 재연결은 `context_fit=forced`와 사유를 남기고 건너뛰며, ‘모든 지정 시점’ 옵션으로도 실행할 수 있다. LLM 판정이므로 적절성을 사후 검토해야 한다.

## 당시 의도 확인 모드

UI의 **분기 상담사 모드 → 당시 의도 확인 · 고정 재질문**을 선택한다. 기본 질문은 `앞서 “{target_quote}”라고 말씀하셨는데, 그때 어떤 생각으로 그렇게 말씀하셨나요?`이며 UI에서 수정할 수 있다. 모드 변경은 새 실험에 적용된다.

- 공통 경로의 공개 이력만 보고 최신 턴을 제외한 과거 발화 하나를 선택한다. 인용을 검증한 뒤 질문 템플릿에 넣어 같은 시점의 A/B·모든 반복에 동일하게 전달한다. 대상은 분기 시점마다 달라질 수 있다.
- 단일 개입·모든 지정 시점으로 자동 설정한다. 시작은 2턴 이상이며, 첫 비교는 분기 길이 1턴을 권한다. 2턴째부터는 기존 상담사가 각 분기 반응에 따라 생성하므로 동일 질문 통제는 첫 질문에만 적용된다.
- 당시 내면을 질문 생성에 제공하지 않는다. 대상 원본은 질문 확정 후 분석 화면에서만 확인한다. `context_fit=diagnostic`은 자연스러움 판정이 아닌 의도적인 재질문을 뜻한다.
- **C 대조 실험을 포함하면 독립 A/C 경로에도 재질문한다.** 각 경로의 지정 시점마다 최신 턴을 제외한 자기 과거 공개 발화를 선택하고 같은 템플릿으로 묻는다. 각 시점에서 질문을 한 번 확정해 설정한 응답 반복·분기 길이에 적용한다.
- A 경로 반복 1은 공통 경로의 A 분기 결과를 재사용한다. 독립 A 반복 2 이후와 모든 C 경로에는 각각 재질문 분기를 만든다. C 분기는 자기 공개 노트와 공개 기록만 복사하며, A의 내면 기록·노트를 받지 않는다. 재질문 답변은 본 경로에 되먹이지 않는다.
- UI **A/C 재질문 비교**에서 같은 경로 반복·분기 시점의 대상 발화, 실제 질문, 반복별 답변과 입력을 나란히 확인한다. 추가 재질문 생성량·진행 상태를 별도로 표시하고 분석 내보내기에도 포함한다.
- A/C는 서로 독립된 과거와 다른 대상 발화를 가진다. 같은 질문 템플릿으로 관찰할 수 있지만 동일 입력에서 기억만 바꾼 비교는 아니다. C에는 당시 내면 기록이 없어 A의 당시 내면을 C의 정답으로 삼지 않는다. 공개 이력과의 일관성·설명의 타당성을 평가한다.
- A/B만 확인하려면 C 대조 실험에서 **A/B 분기만 생성**을 선택한다. 기존 맥락 질문 모드에는 독립 A/C 재질문을 추가하지 않는다.
- 이 모드는 당시 의도 회상·일관성을 먼저 검사한다. 상담 개입의 타당성이나 상담 진전 평가 개선은 별도 검증해야 한다. 노트만으로 충분한 결과도 인정한다.

### C 공개 노트 인용 오류 수정

노트 입력에 메시지 번호를 명시한다. 잘못된 번호라도 인용이 공개 대화의 한 메시지에만 정확히 일치하면 위치만 보정한다. `raw_note_evidence`, `note_evidence`, `note_corrections`와 이벤트 로그에 원래 출력·보정 결과를 남긴다. 번호 변경은 `note_index_corrections`에도 남긴다. 중간이 생략된 인용은 충분히 긴 원문 조각이 같은 메시지에 같은 순서로 유일하게 일치할 때만 누락 부분을 포함한 원문 구간으로 복원한다. 생략된 부정·조건도 함께 복원하며, 이어 붙인 문장을 그대로 노트로 인정하지 않는다. 없는 단어·순서 변경·모호한 위치·서로 다른 메시지의 결합은 오류로 중단하고 실패한 발화를 확정하지 않는다. 프로필 선택·발화·노트 요청도 각각 기록해 실패 지점을 확인할 수 있다.

기존 오류 실험과 결과는 수정하지 않는다. 코드·프롬프트 변경 이후에는 소스 일치 보호에 따라 기존 실험 재개가 제한되므로 새 실험으로 실행한다.

## 사용 방법

1. 앱 서버를 재시작하고 작업 공간의 **Q3p6 분기 실험 ↗** 또는 같은 서버의 `/q3p6`를 연다.
2. 프로필, 모델, 분기 범위를 선택한다. 기본은 **프로필로 새 상담 시작**이다. 프로필을 바꾸면 이전 사례의 대화·출처를 제거하고 첫 질문을 초기화한다. 초기 상태 설정은 JSON에서 확인·조정할 수 있다.
3. 기존 대화를 쓰려면 **직접 구성한 초기 대화 이어가기**를 선택하고 프로필과 맞는 대화·후속 질문을 입력한다. 초기 대화는 내담자 발화로 끝나야 하며 일반적인 첫 인사는 허용하지 않는다. 사례의 의미적 일관성 전체를 자동 검증하는 기능은 아니다.
4. **설정 저장**은 모델을 호출하지 않는다. **자동 실행 / 재개**를 누르면 생성을 시작한다.
5. 필요하면 **연구실 관찰 사례 불러오기**를 눌러 도움을 원하는 마음과 평가 부담이 함께 있는 사례를 선택한다. 특정 의도나 반응을 강제하지 않는다.
6. **실시간 진행 흐름**에서 현재 공통 턴, 분기 단계, A/B 조건, 개입·반복 번호, 저장된 응답 수를 확인한다.
7. 시점별 결과에서 대상 발화·당시 내면, 후속 질문, A/B 반응과 실제 입력을 함께 검토한다. 일시정지 또는 완료 후 ‘미검토 / 분석 후보 / 부적합’과 메모를 저장할 수 있다.

**현재 발화 후 일시정지**는 현재 생성 이후에 멈춘다. **생성 중단**은 현재 요청의 취소를 요청한다. 새로고침은 서버 실행을 중단하지 않는다. 서버 재시작·오류 이후 저장된 실험을 선택해 재개할 수 있으며 완료된 분기는 재생성하지 않는다. 주요 코드·프롬프트가 실험 생성 이후 달라졌으면 재개를 거부한다. 원본 복원 또는 새 실험이 필요하다.

## 기억 조건

| 조건 | 내담자 입력 |
|---|---|
| A / `summary_only` | 공개 대화, 프로필, 현재 상태·목표와 이유도 담을 수 있는 노트 |
| B / `intent_linked` | 동일한 기본 입력 + 완료된 모든 턴의 발화와 당시 확정 내면 기록 |

노트에 있는 이유를 A에서 삭제하지 않는다. 양쪽 모두 과거 원본을 별도 도구로 조회할 수 없으며 B의 기록은 프롬프트에 자동 추가된다.

B의 필드: `turn`, `turn_id`, `counselor_utterance`, `utterance`, `appraisal`, `turn_goal`, `response_plan`, `trajectory_plan`. 모델의 전체 비공개 추론문이 아니다. 최근 12턴 제한이나 자동 절삭을 적용하지 않는다. 문자 예산 초과는 오류로 표시하며, 모델 토큰 한도는 별도다.

## 실행 순서

1. 공통 경로를 A 조건으로 내담자 n턴까지 생성하고 상태를 고정한다. 초기 사례 대화와 첫 상담사 문장은 생성된 내담자 턴 수에 포함하지 않는다.
2. 공개 이력만으로 대상 발화와 후속 질문을 준비한다. 가능한 한 이전 턴의 의향·경계·선택이 드러나는 발화를 고르되, 그런 장면이 없으면 부자연스러운 재연결 여부를 기록한다.
3. 재연결이 자연스러운 시점에서 기본 **I1 하나**를 A/B에 전달한다. 선택한 **두 개입 모드**에서는 I2도 준비한다.
   - I1: 대상 발화의 맥락을 이어 현재 반응을 묻는 질문.
   - I2: 같은 주제의 부담·선택권·속도를 확인하는 질문.
4. 같은 질문과 첫 응답의 특성 라우터 선택을 A/B·반복에 재사용한다. 같은 반복 번호의 A/B에는 같은 시드를 사용한다.
5. 분기는 독립 저장한다. 모든 개입·반복이 끝나면 공통 경로를 한 턴 진행하고 반복한다. 분기 반응을 공통 경로에 반영하지 않는다.

수락·망설임·거절·자기개방·기타 공개 표현 모두 대상이다. `relevance=potential/weak`는 연구 관련성 참고 판단이며 자체로 실행을 막지 않는다. 별도의 `context_fit=natural/forced`가 현재 대화 흐름과의 연결을 표시한다. 잘못된 인용이나 형식 오류는 멈추고 오류를 표시한다. 이 경우도 조건을 충족하지 않았다는 미수행으로 바꾸지 않는다.

대상 내면 기록은 후속 질문 생성 후 별도로 읽어 검토 화면에 표시한다. 상담사 입력에는 전달하지 않는다. 대상 이후 경과 턴 수도 표시한다. 현재 턴이 대상이면 0턴으로 표시하며 장기 기억 효과 사례로 간주하지 않는다.

## 실시간 표시와 사례 검토

- 화면은 약 1.5초 간격으로 갱신한다. 공통 생성 → 질문 준비 → A → B → 다음 공통 턴의 단계를 보여준다.
- 상담사 공개 발화는 스트림을 누적해 보여준다. 내담자는 공개 발화가 작성되면 먼저 표시하고, 노트·궤적 저장 전에는 미확정 상태임을 알린다. 비공개 추론이나 도구 JSON을 공개 발화로 표시하지 않는다.
- 개입 질문 생성의 구조화된 중간 JSON은 공개 발화로 표시하지 않으며, 완료 후 원문을 결과에 보여준다.
- ‘실행 완료’는 조건별 생성이 끝났다는 뜻이다. ‘분석 후보’는 사용자의 검토 표시이고 가설 입증이나 우월성 판정이 아니다.
- 과거 내면이 이미 공개되어 있는지, 후속 질문에 실제로 관련되는지, 현재 변화나 추가 정보량으로 차이를 설명할 수 있는지 검토한다.

## 기본값과 해석 범위

기본값은 공통 **2~20턴**, 개입 **1개**, 분기 후 내담자 **1턴**, 조건별 **5회**, 입력 문자 예산 **240,000자**다. A/B 분기 응답은 최대 19 × 1 × 2 × 5 = **190개**다. C 비교를 포함하면 독립 A/C 5회씩 20턴, 총 200개(공통 A 20개 포함)가 추가 축으로 생성되어 내담자 응답은 최대 **390개**다. 공통 A를 중복 생성하지 않는다. 상담사·질문 준비·라우터·노트 호출은 별도다. UI에 예정 건수를 표시하며 설정 저장만으로 실행하지 않는다.

이 실험은 **전체 기록 묶음의 추가 효과**를 비교한다. 특정 한 턴의 효과나 발화 연결 방식 자체의 독립 효과는 분리하지 않는다. B가 반드시 더 타당한 것은 아니다. 공통 경로가 A에서 생성되므로 해당 경로에서 방문한 상태에 대한 결과이며, 반복 5회는 탐색용이다.

분기 길이는 최대 5턴이다. 두 번째 내담자 응답부터는 각 분기의 대화에 맞춰 상담사가 후속 발화를 생성하므로 동일 입력 비교는 첫 응답에만 적용되고 이후는 궤적 비교다.

## 독립 C 대조 조건

C는 같은 초기 프로필·대화·초기 상태와 모델 설정에서 시작하며 A의 체크포인트를 복제하지 않는다. 기존 Q3 프로필 라우터로 자기 대화에 관련된 특성·배경을 선택하고, 실제 발화를 직접 생성한다. 명시적 appraisal·turn_goal·response_plan·trajectory_plan 단계는 없다.

노트 생성에는 C의 공개 대화만 제공하고, 실제 발화의 인용과 위치를 검증해 저장한다. 추론한 숨은 이유나 A/B 노트는 포함하지 않는다. 모델의 내부 추론 자체가 사라진다는 의미는 아니다. C의 공개 노트 갱신은 최대 128개 인용을 선택하는 방식이다.

A/C는 생성 과정과 노트 방식도 다르므로 전체 방식의 비교다. 같은 반복 번호는 초기 사례와 시드를 맞추지만, 대화가 달라진 뒤 상담사 발화나 라우터 선택까지 같지는 않다. A/B 공통 경로를 A 반복 1로 재사용하고, A/B 분기가 끝난 뒤 독립 C 및 추가 A 경로를 순차 생성한다. 각 독립 경로는 마지막 분기 턴 설정까지 생성한다. C는 분기 결과 표와 별도의 화면에서 확인한다.

## 사후 분석 자료

완료 또는 일시정지 후 **원본 분석 자료**에서 모든 조건·경로·입력·내면·노트·결과 및 매핑 키를 JSON으로 받는다. **평가용 공개 대화**는 순서를 섞은 식별자와 공개 대화만 포함하며 조건·내면·검토 표시는 포함하지 않는다. 공개 대화 진전 해석용이다. 내부 일관성 평가는 원본 자료를 별도로 대조해야 하며, 익명 자료만으로 당시 비공개 의도를 평가할 수 없다.

자연스러운 연결 여부를 포함한 생성 시점 선택은 공개 대화 기반이다. 평가 기준이나 성공 판정을 생성 과정에 되먹임하지 않는다. 5회 반복은 탐색용이고 3턴 분기는 별도 궤적 분석이다.
