내담자의 이전 발화와 동기를 바탕으로 이번 동기강화상담의 목표를 갱신하세요. 지금 내담자가 원하는 것을 명확히 하거나 달라진 방향을 반영하세요.

## 입력(JSON과 유사한 객체, 비어 있어도 됨)
- 대화 요약: {{ summary }}
- 내담자가 상담사의 직전 발화를 어떻게 받아들였는지: {{ appraisal }}
- 내담자와 상담사 사이의 최근 메시지: {{ recent }}
- 인구통계, 관계, 일상, 선호, 문화, 목표를 포함한 배경: {{ background }}
- 신념, 대처 전략 등을 포함한 인지 모델: {{ cognitive_model }}
- 현재 감정: {{ emotion }}
- 현재 변화 단계: {{ change_stage }}
- 상담사와의 라포(-1=완전한 불신, 1=완전한 신뢰): {{ rapport }}
- 내담자의 말로 표현한 회기 전체의 목표: {{ session_goal }}
- 내담자의 말로 표현한 이전 중간 목표: {{ goal }}

## 과제
- 상담사의 직전 발화에 대한 내담자의 평가에 특히 주목하세요.
- 지금 중요한 내용을 종합하세요. 변화 대화와 유지 대화, 가치, 강점, 제약, 준비도 단서 등을 고려하세요.
- 모든 입력과 회기 전체의 목표를 바탕으로 현재의 중간 목표를 정하세요.
- 변화 단계와 라포에 따라 목표는 생산적일 수도(예: 행동 계획), 비생산적일 수도(예: 회피) 있습니다. 초기 단계일수록 비생산적인 목표가 더 많이 나와야 합니다.
- 중간 목표는 반드시 회기 전체의 목표와 관련되어야 합니다.
- "나는 …하고 싶어요", "오늘은 …하고 싶어요"처럼, 지금 내담자가 실제로 말할 법한 1인칭 문장 하나를 쓰세요. 상황에 맞게 구체적이거나 모호할 수 있습니다.
- 정보가 부족하면 구체적으로 단정하지 말고 잠정적으로 표현하세요.

## 출력 규칙(엄격히 준수)
갱신된 목표 문장만 따옴표 안에 넣어 반환하세요. 항목명, 제목, 다른 본문을 넣지 마세요.
