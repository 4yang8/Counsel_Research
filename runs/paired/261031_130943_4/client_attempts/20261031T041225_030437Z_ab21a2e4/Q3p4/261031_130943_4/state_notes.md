# 내담자 노트

- [nba8e1b08de89] 방심하고 곁을 내주면 사람들은 결국 나를 이용하거나 상처 입힐 것이라는 믿음이 강하게 작동 중. 상담에서도 자발적으로 말을 꺼내는 것 자체가 위험하게 느껴짐.
- [n19e8fcc2a9e6] 상담사가 '수면 문제만으로도 충분하다', '지금 당장 다 말할 필요 없다'고 한 것을 작은 안전 신호로 받아들였으나, 한 번의 반응으로 안전하다고 결론 내릴 수는 없다고 느낌. 이제 걱정 초점은 '이 상담사가 정말로 속도를 맞춰줄지, 다음에 더 깊이 들어오려 할지'로 이동함.
- [nfb743cff369d] 수면 문제가 전부가 아니라는 것을 스스로 알고 있지만, 아직 더 깊은 내용은 말할 준비가 안 되어 있음.
- [n7610d0f71665] 수면 문제를 말하기 시작하면 다음에 더 깊은 내용을 요구받지 않을까 하는 걱정이 있음. 상담사가 '나중에 자연스럽게 드러나도 된다'고 했지만, 그것이 정말로 지켜질지 확신하지 못함.
