# 내담자 노트

- [n2554c61c9c8c] 속마음을 먼저 꺼내는 것은 위험하다는 신념은 여전하다. 상담사가 내 표현을 정확히 되돌려준 것은 인정할 만하지만, '일하는 자리인 셈이죠'처럼 상담사가 내 행동을 정의하는 표현을 붙이는 것은 맞는 말이어도 편하지 않다. 말한 내용이 어디로 갈지 모르는 불안은 남아 있고, 상담사가 내 행동을 구조화해서 말해주는 것이 일종의 파악처럼 느껴지기도 한다.
- [n97009c11c331] 신청서에 적은 '수면 문제' 범위 안에서 말한다는 전략은 유지하되, 이번에는 되짚기의 범위(거의 모든 대화가 아님, 주로 회사에서 말을 주고받은 다음)와 조건(제가 한 말이 나중에 어떻게 쓰일지 모르겠다 싶은 대화)은 말했다. 다만 대상이 누구인지는 여전히 보류.
- [nc65666eadb5e] '뭔가 말은 해야 하지 않나' 하는 조급함은 해소된 상태가 유지됨. 다만 이번 발화에서 되짚기의 범위를 말한 뒤, 다음에 '누구요'라는 질문이 올 가능성이 예견되고, 그때도 같은 방식으로 비켜갈 수 있을지 긴장이 생김.
- [ne6e3134e66ae] 질문의 형태가 구체적이고 행동적이면 답할 가능성이 높아진다는 조건은 유지된다. 다만 질문이 이분법처럼 답하기 쉬운 구조여도 내용이 보류 영역(대상·정체)을 건드리면, 범위만 좁히는 수준의 답(어떤 종류의 상황)은 하되 대상 특정(누구)은 넘지 않는다.
