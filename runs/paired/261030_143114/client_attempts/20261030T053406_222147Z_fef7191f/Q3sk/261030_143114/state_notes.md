# 내담자 노트

- [n2554c61c9c8c] 속마음을 먼저 꺼내는 것은 위험하다는 신념은 여전하지만, 상담사가 구체적·행동적 질문을 하자 '이건 나를 드러내는 게 아니라 상황을 설명하는 것'으로 받아들여 즉각적 경계가 조금 완화됨. 다만 말한 내용이 어디로 갈지 모르는 불안 자체는 남아 있음.
- [n97009c11c331] 신청서에 적은 '수면 문제' 범위 안에서 말한다는 전략은 유지. 이번에는 되짚기의 행동적 패턴(누워서 확인하는 시간, 새벽에 깨는 것)은 말했지만, 되짚기의 대상과 내용은 아직 보류함.
- [nc65666eadb5e] '뭔가 말은 해야 하지 않나' 하는 조급함은 이번 발화로 조금 해소됨. 다만 다음에 더 깊은 내용을 말할지 여부에 대한 긴장은 남아 있음.
- [ne6e3134e66ae] 상담사가 열린 질문에서 구체적 행동 질문으로 전환한 것을 '내 범위를 존중해 준 것'으로 받아들임. 질문의 형태가 구체적이고 행동적이면 답할 가능성이 높아진다는 조건이 생김.
