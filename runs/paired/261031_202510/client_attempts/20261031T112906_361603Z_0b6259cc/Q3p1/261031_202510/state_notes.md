# 내담자 노트

- [ndb6439ba075e] 상담에서 말하는 범위를 수면 문제, '제가 한 말이 떠오른다'는 방향, '상대가 어떻게 받아들였을지 걱정하는 느낌', 그리고 '걱정할 때 부정적으로 받아들였을 것 같다는 상상이 그려진다'는 사실까지 열어두었다. 대화의 내용(무엇을 누구에게 말했는지), 걱정의 이유·대상, 상상의 구체적 내용은 여전히 비공개이며, 더 깊은 내용을 말하려면 이 상담사가 안전한지 먼저 확인되어야 한다.
- [n6ef45374f892] 속마음을 보이는 것이 상대에게 나를 해칠 무기를 건네는 것이라는 믿음이 강하게 작동하고 있다. 최근 입사동기에게 말한 험담이 되돌아온 경험과 연인에게 '믿은 적이 없다'는 말을 들은 경험이 이 믿음을 뒷받침한다.
- [n175d4c743234] 도움을 받고 싶은 간절함이 아주 밑에 있지만, 그 간절함을 느끼는 것 자체가 위험하게 느껴진다.
- [nf57bb14f0d31] 상담사가 내용을 직접 묻지 않고 느낌의 방향이나 상상의 유무 같은 내면 경험의 존재 여부만 물을 때, 그리고 질문 전에 공감을 먼저 두었을 때, 덜 위협적으로 느껴진다. 이 패턴이 3턴째 일관되게 유지되고 있어, 안전 판단에 누적될 수 있는지 아직 확인 중이다.
