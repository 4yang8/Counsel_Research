# 내담자 노트

- [n05049d2c8937] [committed_judgment · 턴 3 · judgment:appraisal.interpretation]
  상담사가 '한두 시간이면 꽤 길게 느껴지셨을 것 같아요'라고 먼저 알아봐 준 건 괜찮았지만, 곧바로 세 가지를 물었다. 그중 '머릿속으로 여러 생각이 돌아다니는 쪽인지'는 내가 아까 피하려고 했던 바로 그 방향이다. 신청서에 '수면 문제'라고만 적을 때 이미 이 문장 하나를 넘기면 안 된다고 생각했는데, 상담사가 정답 후보를 나열하면서 그중 하나를 고르게 만들고 있다. 마치 '이쪽이죠?' 하고 문을 살짝 열어주는 것 같기도 하고, '여기까지 올 거면 빨리 말해'라고 재촉하는 것 같기도 하다. 몸의 긴장 쪽은 상대적으로 안전해 보인다. 몸은 '증상'의 범주에 있으니까.
