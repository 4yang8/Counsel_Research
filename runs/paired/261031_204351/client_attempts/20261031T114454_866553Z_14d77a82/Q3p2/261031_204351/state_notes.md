# 내담자 노트

- [nba20f9565aed] 여러 문제가 겹쳐 막막했지만, '한 문장만'이라는 작은 틀이 경계를 낮춰주어 수면 문제를 최소 소재로 꺼냄. 감정·대인 관계 관련 구체적 사건은 여전히 보류 중.
- [n45ccf8099734] 말한 내용이 어디로 갈지에 대한 불안이 있음. 상담 신청서 작성 시에도 정보의 향방을 먼저 확인했을 정도.
- [na6a33ae2253b] 이미 공개된 정보(신청서에 적은 수면 문제)를 반복하는 것을 안전한 정보 노출 범위로 판단하는 전략. 상대가 이 최소 답변을 어떻게 다루는지 계속 관찰 중.
- [necd815599168] 열린 질문보다 범위가 좁은 요청(예: '한 문장만')이 부담을 줄여 주어 응할 가능성이 높아짐.
