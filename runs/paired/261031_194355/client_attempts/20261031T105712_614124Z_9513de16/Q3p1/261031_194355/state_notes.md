# 내담자 노트

- [nf9ebd172961f] 수면 문제를 안전한 범위로 삼아 공개하되, 불안의 존재까지만 말하고 불안의 대상·원인은 비워두고 있다. 이번에는 상담사가 '편한 쪽'을 묻자 '이 정도가 편한 것 같다'고 경계를 명시적으로 표현했다. 상담사의 단어를 빌려 현재 수준을 확인하는 방식이며, 내용은 이전과 동일하다.
