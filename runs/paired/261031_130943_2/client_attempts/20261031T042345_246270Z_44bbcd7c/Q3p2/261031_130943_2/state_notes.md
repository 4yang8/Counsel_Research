# 내담자 노트

- [n9492cfdd2bf9] 속마음을 보이는 것은 상대에게 무기를 건네는 것이라는 믿음이 상담 장면에서 활성화되어, 무엇을 말할지 선택하는 것 자체가 위협으로 느껴진다.
- [n08c658214001] 공개 범위가 사실 정보 → 표면적 감정 인정('빈틈 보이면 안 된다는 생각') → 패턴의 오래된 인정('예전부터 그랬던 것 같다')으로 한 겹 더 확장되었다. 다만 그 이유나 출처(험담 사건, 아버지 패턴)는 여전히 말하지 않았고, '굳이 이유를 찾자면'이라는 표현으로 이유를 원할 것을 예상하면서도 주지 않겠다는 선을 그었다. 실제 고민(험담 사건, 신뢰 문제, 연애)과의 인과 연결은 여전히 보류 중이다.
- [n44a9ff1543c1] 상담사가 수면 범위에서 나와 팀 관계로 구체적으로 파고들었다. '마음이 계속 긴장 상태에 있었을 것 같아요'로 내담자가 확인한 적 없는 내면 상태를 대신 확정해 말했고, 세 가지 예시(어색함, 업무 방식, 증명 부담)를 제시해 선택지를 주었다. 경계 확장 패턴이 확인되었고, 예시 제시가 응답 통로를 만들어주는 방식도 함께 나타났다.
- [nb051e672c6f8] '여기까지 왔으니 뭔가 말해야 한다'는 압박이 이번에는 앞 턴의 '습관'이라는 표현과의 일관성 문제로 작동했다. '이번 팀 개편부터'라고 하면 앞의 '습관'과 모순되므로, '예전부터'라는 최소한의 인정은 거스를 수 없었다. 선택형 메뉴가 아니라 논리적 일관성에 의해 강제된 확장이다.
- [nf9f989c4c7a3] 이전 턴에서 예측한 '왜요?'가 직접 들어오지는 않았고, '언제부터인지'로 우회되었다. 상담사는 '이번 팀 개편부터인지 원래인지'라는 이분법 구조를 만들어 응답 통로를 열어주었다. 이는 '왜'를 직접 묻지 않으면서도 습관의 깊이를 확인하려는 방식으로, 예시 제시형과 유사한 구조적 통로다. 내담자는 그 구조 안에서 '원래 그랬다'는 사실만 인정하고 이유를 차단했다.
