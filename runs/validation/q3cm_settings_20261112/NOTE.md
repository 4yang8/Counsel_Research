# Q3cm 이름 및 마지막 UI 설정 복원

목적: 신규 내담자 7종에 Q3 접두사를 적용하고, 생성/평가 입력을 재접속 시 복원한다.

신규 이름: Q3cm, Q3cm_split, Q3cm_temporal, Q3cm_state, Q3cm_tools, Q3cm_review, Q3cm_full. 기존 cm 계열은 호환 런타임과 원래 저장 경로를 유지한다. 일반 카탈로그의 legacy 항목은 숨겨진 옵션으로 제공하여 기존 세션 복원을 지원하고, 신규 대량생성 목록은 Q3 이름만 표시한다. 실제 시스템/보조 프롬프트 본문은 원본과 바이트 단위로 동일함을 확인했다.

설정: 같은 origin의 브라우저 localStorage에 생성/평가/기존 batch 페이지별 입력을 저장한다. 저장은 사용자 입력 시 수행하며 기존 작업의 고정된 설정을 변경하지 않는다. 프로필 선택은 확인된 폴더 경로와 연결한다. 빈 선택, 미확인 경로, 없는 경로에서도 다른 설정과 작업을 유지한다.

검증:
- targeted.log: 새 내담자 전체 분기·역사정보 차단, legacy cm_full 실행, 조합 생성과 평가 연결 등 24개 통과.
- browser_workbench.log: 2x2 모의 생성, 준비만 평가, 그래프, 재접속 시 서버/옵션/버전/프로필/평가 설정 복원 확인. 최초 실행은 iframe 작업 상태 대기에서 timeout이 있었으며 진단 출력 추가 후 재실행 통과.
- browser_compare.log: 기존 대량생성 설정 및 빈 프로필 선택의 재접속 복원, 프롬프트 편집 검사.
- full_initial.log: 370개 중 3개 실패. 신규 목록에서 legacy를 제거한 카탈로그 호환 검사 2개는 legacy 메타데이터와 숨겨진 옵션으로 보완했다. 서버 시작 제한시간 실패 1개는 재실행에서 통과.
- recheck.log: 실패 검사와 서버 종료 검사를 다시 실행하여 4개 통과. 보완 뒤 전체 370개를 재실행하지는 않았다.

원본 결과/실패 기록을 변경하지 않았다. 실제 모델 생성 또는 유료 codex 평가 호출은 하지 않았다.
