# P3q 상담사 실제 모델 확인 (2026-11-11)

- **목적:** P3q의 한 번 호출(발화 + 되짚기 표시, 구조화 출력)이 실제 모델 서버에서 동작하는지 확인한다. 연구 결과 판정용이 아니다.
- **조건:** 모델 `Qwen/Qwen3.8-27B-FP8`, 서버 `http://127.0.0.1:18001/v1`. 내담자 발화는 직접 쓴 예시(`hidden_reaction_pairs/02_gold_002_provided.txt`)의 앞 7개를 순서대로 직접 입력했고, 상담사 발화만 모델이 생성했다.
- **결과:** 상담사 발화 7개가 모두 정상 생성됐다. 표시 7개 모두 형식이 올바르고(`valid: true`), 되짚기로 표시된 2개는 인용이 원문에 있었다(`quote_found: true`). 표시는 공개 대화에 들어가지 않았다.
- **주의:**
  - 시험용 스크립트가 실험 화면의 기본 시나리오를 그대로 써서, 앞 5턴에 무관한 예시 대화가 들어갔다. 대량생성에서는 초기 예시 대화를 넣지 않으므로 이 문제는 생기지 않는다.
  - 내담자 발화는 상담사 발화에 맞춰 쓴 것이 아니라 정해진 문장을 차례로 넣은 것이라 대화가 어색하다.
  - 13턴 표시는 8턴을 가리켰지만 발화 내용은 직전(12턴) 내담자 말에 대한 것이었다. 표시가 발화와 항상 맞지는 않으므로, 실제 분석 전에 표시 정확도를 따로 확인해야 한다.
