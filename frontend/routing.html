지표와 읽는 방법
  • 열의 턴 번호는 내담자 판단·발화 횟수입니다. 공개 대화 20개 발화는 일반적으로 내담자 10턴입니다. 실패·미완료 시도와 복사된 과거 기록은 중복 집계하지 않습니다.
  • 노트 히트맵은 해당 턴의 판단 전에 존재했던 노트입니다. 이번 턴에 새로 작성한 노트는 다음 턴부터 선택 후보가 됩니다. 회색은 후보였지만 선택하지 않은 항목, 색칠된 칸은 선택한 항목입니다.
  • 노트 선택률 = 선택 항목 수 / 당시 후보 수. 후보가 없는 첫 턴과 기록 누락은 0% 대신 ‘—’로 표시합니다. 요약 비율과 원문 항목 비율은 정보량의 동일성을 뜻하지 않습니다.
  • 연속 재선택률 = 직전 선택 항목 중 현재도 후보인 항목을 다시 선택한 비율. 이미 교체된 ID는 분모에서 제외합니다. 새 ID는 새로운 심리 내용과 동일하지 않습니다.
  • 특성 빈도는 해당 ID가 후보였던 기록 턴을 분모로 사용합니다. 같은 배경이 여러 특성에 연결돼도 턴당 한 번만 셉니다. 노트 나이는 항목 ID의 생성 시점 기준이며, 요약문에 담긴 과거 경험의 시점과 다릅니다. 생성 시점이 확인된 항목만 계산합니다.
  • 노트 종류는 저장된 필드·출처 표기에서 읽습니다. 주제를 새 모델로 분류하지 않습니다. 노트별 선택 이유는 원기록에 없으므로 선택 여부와 원문으로 확인합니다.
