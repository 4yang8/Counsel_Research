# 2026-10-29 구조 정리

## 목적

진행 중인 `gemma_test/counseling_test`를 메인으로 올리고, 중단한 C/V 연구를 보관한다.
코드 위치와 import를 바꾸되 모델 지침·상태·기억·계획의 연구 조건은 유지한다.

`archive/tool_practice/gemma_test/counseling_test`의 이전 앱 소스는 이동 전 구성 확인용이다.
메인 개발·실행 위치가 아니다. 고유 연구 자료는 삭제하지 않았다.
실험 안에 고정된 소스·프롬프트 사본은 당시 실행 근거이므로 일괄 치환하지 않았다.

## 호환

- C4는 보관된 구현을 필요할 때 불러오는 별도 경계로 유지한다.
- 과거 세션의 `storage_dir`, `client_storage_dir`, 단계별 `saved_path`는 읽을 때만 새 위치로 해석한다.
- 외부 저장 경로는 그대로 사용한다. 모델 입력·설정·대화 원문은 변환하지 않는다.
- 모델·서버·생성 설정은 유지하고 자료 경로와 기본 저장 위치만 변경한다.
- 기본 세션 저장 위치는 `runs`이며 다른 위치는 `--config`로 지정한다.

## 이동 전 검사

모의 모델 unittest 204개 중 202개 통과, 기존 실패 2개 확인.

- P3a 테스트가 빈 노트의 `(내용 없음)` 표시를 고려하지 않았다.
  원본 템플릿의 제목과 내용 보존을 검사하도록 수정했다.
- Prefill 테스트가 별도로 발전한 프롬프트를 기준 버전과 같다고 가정했다.
  각 원본과 일치하는지, 편집 후 상대 버전에 영향이 없는지를 검사하도록 수정했다.

- 실제 프로젝트 위치의 workspace 브라우저 검사: 독립 탭 6개, 설정 동기화, 배경 생성, 새로고침, 탭 종료 후 세션 보존, 모바일 통과.

- 이전 브라우저 선택 키로 Q3/Q3a/Q3b 기록 조회 및 실제 호출 파일·비공개 노트 경로 확인.

## 추가 정리

Q1_s1/Q1_s2와 상담사 비교 조건이 사용하던 보조 실험의 재시도 루프는
`src/runtime/recovery_tool_loop.py`로 옮겼다. 현재 앱이 `experiments`의 Python 경로에
기대지 않고 실행되도록 했다. 이전 보조 실험 실행기는 `experiments/side_experiments`에 남겼다.
기존 Git의 `experiments/codex_car*` 삭제 상태는 되돌리거나 새 자료로 대체하지 않았다.
새 세션 경로를 해석할 때도 원본 기록에 저장된 프롬프트와 대화는 수정하지 않았다.
