# 연구 방향과 수정 원칙

- **프로필 일관성:** 프로필을 바탕으로 일관되게 구체화한 생각·발화는 허용한다. 원문에 없는 세부 표현이라는 이유만으로 오류로 판단하지 않는다.
- **단계별 역할:** 내면 판단에서 해석·감정을 생성하고, 표현 선택에서 공개 범위를 정한다. 기록은 앞에서 실제로 생성된 생각·감정·선택·발화를 보존한다.
- **기록의 충실성:** 필요한 내용을 선별·요약하되 대상·의미·시점·확실성을 유지한다. 기록 과정에서 임의의 해석, 새로운 인과관계·상대의 의도·관계 변화·결과를 덧붙이지 않는다.
- **내면과 관찰 구분:** 내담자가 느끼거나 예상한 것과 실제 상호작용으로 확인한 것을 구분한다. 아직 관찰하지 않은 반응을 확인된 경험으로 기록하지 않는다.
- **근본적인 수정:** 개별 실패 문장을 막는 예외 규칙을 누적하지 않는다. 단계의 목적·입력의 의미·판단 권한·출력의 근거 범위를 명확히 하고, 프롬프트와 도구 설명에 일관되게 적용한다.
- **검증 기준:** 설계 의도 → 중간 판단 → 다음 단계 입력 → 실제 발화의 연결을 확인한다. 동작 여부, 고유한 기여, 비용을 구분하며 단일 사례의 차이를 인과효과로 단정하지 않는다.
