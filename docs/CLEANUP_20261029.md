## 코드 연결

- 필요한 `Cancelled` 예외를 `src/runtime/cancellation.py`로 분리했다.
- 비활성 Filesystem MCP 실행·도구 목록·지침 삽입 분기를 HTTP 서버에서 제거했다.
  상담용 도구는 기존처럼 앱과 각 연구 버전이 제공한다.
- 보조 실험의 `tool_loop.py`는 공통 `runtime/recovery_tool_loop.py`를 불러오는 짧은 호환 파일로 바꿨다.
- 보조 실험 실행기에 남은 옛 소스 경로를 수정했다. 새 고정본은 현재 `src`, 연구 입력 자료,
  앱 설정, 보조 실행 코드와 실행 스크립트를 보관한다. 소스가 누락되면 복사 전에 실패하고,
  기존 고정본을 덮어쓰지 않는다.
- 과거 실험에 이미 저장된 고정본·세션·실패 기록과 버전별 프롬프트는 이동·수정하지 않았다.
- `trashcan/`은 Git·패키지·테스트 실행 대상에서 제외했다.

## 확인·복원

`trashcan/README.md`의 안내와 해당 배치의 `manifest.json`을 확인한다.
`original`은 원래 위치, `stored`는 보관 위치이며 `action`으로 이동과 변경 전 사본을 구분한다.
기존 경로에 새 파일이 있으면 먼저 비교한다. 코드 변경을 되돌릴 때는 중단 처리 분리와
공통 import 변경을 함께 검토한다. 사용자 확인 없이 보관함을 영구 삭제하지 않는다.
