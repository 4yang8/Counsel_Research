# 기법 선택 가이드 · Common / MI / CBT

## 선택 기준

| 접근 | 선택 기준 |
|---|---|
| Common | 현재 경험을 이해하고, 의미·관계·원하는 도움·방향을 협의하는 대응이 중심일 때 |
| MI | 특정 변화에 대한 내담자 자신의 이유·의지·양가감정·자율성을 다루는 대응이 중심일 때 |
| CBT | 현재 문제와 관련된 생각·행동을 공동으로 이해·검토하거나 합의한 작업을 이어갈 때 |

Common / MI / CBT를 정해진 순서대로 거칠 필요는 없습니다. 공감·반영·요약·협력 같은 행동은 여러 접근에서 사용할 수 있으므로, 행동의 겉모양보다 현재 목적을 함께 보세요.

## 선택 시 주의사항

- 첫 세션이라는 이유만으로 CBT를 배제하지 마세요. 첫 세션에서 CBT를 반드시 사용해야 하는 것도 아닙니다.
- MI는 CBT를 시작하기 전뿐 아니라 변화 과정 전반에서 사용할 수 있습니다.
- Common에는 질문 외에도 관계·감정·의문·불일치에 대한 대응과 방향 협의가 포함됩니다.
- 원하는 도움(desired_help)이 미확인이라는 이유만으로 다른 작업을 일괄적으로 금지하지 마세요. 협력 원칙과 특정 노트 항목을 필수 통과 조건으로 삼는 것은 다릅니다.
- 기법 전환 횟수만으로 적절성을 판단하지 말고, 다음 행동과 내담자의 실제 반응을 함께 보세요.

## 매 턴 판단할 질문

- 지금 내담자는 무엇을 이야기하거나 요청·수정하고 있나요?
- 이미 무엇을 알고 있으며, 이번 대응에 필요한 어떤 부분이 부족한가요?
- 더 질문해야 하나요, 확보한 내용을 반영·정리·활용할 수 있나요?
- 현재 접근에서 어떤 행동이 이 필요에 맞나요?
- 이전 대응에 대한 실제 반응은 지금 선택을 어떻게 바꾸나요?
