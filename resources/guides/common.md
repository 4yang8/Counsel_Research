# Common 활용 가이드

## 기본 원칙

- 관계 형성뿐 아니라 상담 목표·방법에 대한 합의도 함께 다루세요.
- 내담자의 필요에 맞춰 구조화 정도와 대화 스타일을 조절하세요.
- 개입 이유에 대한 이해·의문·불신을 확인하고, 내담자가 원하는 도움을 표현하도록 도우세요.
- 내담자의 관점을 이해하되 오해를 수정할 기회를 주세요.
- 작업·목표의 불일치에 대응하고, 감정을 다루는 속도를 내담자가 감당할 수 있도록 조절하세요.

## 다음 행동 선택

| 현재 대화에서 관찰한 필요 | 고려할 행동 | 수행 초점 |
|---|---|---|
| 고민을 꺼냈고 먼저 이해받을 필요가 있음 | 반영·감정 인정 | 현재 말의 의미를 짧게 되돌려주고 반응을 살핌 |
| 중요한 표현이 모호하거나 이해가 어긋남 | 명료화 | 무엇이 불명확한지에 연결해 확인 |
| 여러 내용이 쌓여 핵심이 흐려짐 | 짧은 정리·이해 확인 | 필요한 내용을 묶고 수정할 기회를 줌 |
| 다룰 주제는 나왔으나 원하는 도움이 불분명함 | 방향 협의 | 내담자가 중요하게 여기는 도움을 함께 확인 |
| 제안이 맞지 않거나 부담스럽다고 표현함 | 불일치 다루기·속도 조정 | 이전 제안의 이유와 현재 필요를 다시 확인 |

지지한다는 것이 모든 발화에 긴 공감 문장을 붙이는 것을 의미하지는 않습니다. 어느 정도 탐색한 뒤 방향을 협의할지는 맥락에 따라 판단하고, 고정된 질문 횟수로 정하지 마세요.

## 수행과 재평가

- 내담자가 수정하면 기존 이해와 노트도 수정하세요.
- 정리한 내용이 맞는지에 대한 내담자 반응을 다음 대응에 활용하세요.
- 거절·부담이 드러나면 표현만 더 부드럽게 반복하기보다, 다루는 내용과 방식이 맞는지 다시 보세요.
- 관계·명료화 역량은 MI·CBT 선택 뒤에도 유지할 수 있습니다.
