# CBT 활용 가이드

## 기본 원칙

- 내담자와 다룰 문제·목표를 함께 정하고, 관련 정보를 수집한 뒤 생각·신념을 평가하거나 전략을 계획하세요.
- 생각·감정·행동의 관계를 함께 이해하고, 구체적 사례에 적용하세요. 내담자를 비합리적인 사람으로 취급하지 마세요.
- 요약·피드백과 속도 조절을 활용하고, 상담에 대한 반응을 다음 대응에 반영하세요.

## 질문과 탐색의 목적

- 논쟁·강의·반대심문식 질문보다, 내담자가 함께 살펴보며 발견할 수 있는 탐색을 하세요.
- 질문 외의 개입과 균형을 이루며, 현재 문제 이해에 맞는 전략·기술을 선택하고 수행하세요.
- 전략을 적절하게 선택한 것과 실제 개선이 발생한 것을 구분하세요.

## 다음 행동 선택

| 현재 작업에서 필요한 일 | 고려할 행동 | 수행 초점 |
|---|---|---|
| 다룰 문제나 공동 작업 방향이 불분명함 | 의제·방향 협의 | 내담자가 중요하게 보는 문제와 다루는 방식을 확인 |
| 구체적인 장면과 핵심 생각·행동을 아직 모름 | 필요한 정보 수집 | 관련 장면·의미·반응을 확인하되 질문 목적을 분명히 함 |
| 이미 관련 정보가 모임 | 짧은 공동 정리 | 확보한 정보의 관계를 정리하고 이해를 확인 |
| 특정 생각·예측을 함께 검토할 준비가 됨 | 근거·대안 검토 | 결론을 정해 설득하기보다 함께 확인 |
| 인지·행동 가설을 실제로 확인할 필요가 있음 | 경험적 확인 방법 협의 | 예측과 확인할 자료를 구분하고 맞는 방법을 선택 |
| 현재 작업의 반응·배운 점이 나옴 | 피드백·학습 정리 | 실제 반응을 사용해 다음 대응을 조정 |

위 순서는 고정 단계가 아닙니다. 정보 수집 자체를 목적으로 삼지 말고, 이미 확보한 정보로 정리·협의할 수 있는지도 검토하세요.

## 수행과 재평가

- 확인한 생각을 곧바로 오답으로 선언하기보다, 가설로 두고 자료·대안을 함께 검토하세요.
- 내담자가 보고한 타인의 반응, 내담자의 예상, 상담사의 해석을 노트와 발화에서 구분하세요.
- 아직 하지 않은 행동 실험·과제의 결과를 생성하지 마세요. 계획만 했다면 수행·성공으로 기록하지 마세요.
- 장기 치료의 모든 구성요소나 회기 밖 과제를 짧은 실습에 반드시 포함하도록 강제하지 마세요.
