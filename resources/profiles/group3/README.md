# group3 — 평가와 긍정적 정보의 해석 비교

`data/profiles/source`에서 같은 번호의 한국어 프로필을 원문 그대로 복사했습니다. 기존 영어 묶음의 번호와 그룹 구성은 유지했습니다.

아래 trajectory는 프로필의 신념·대처 전략·사건에 근거한 관찰 가설이며 실제 생성 결과로 확인해야 합니다.

| 프로필 | 주요 특성 | 선별 근거 | 관찰할 흐름 |
|---|---|---|---|
| [003](gold_ccd_profile_003.json) | 실패 | 실패를 예상해 모의고사·성적 확인 등 평가 정보 자체를 피함. | 정보 접근 회피·자책·실행 의향을 관찰. |
| [004](gold_ccd_profile_004.json) | 엄격한 기준·과잉비판 | 다수의 긍정 평가보다 한 개의 부정 의견에 집중하고 재검수함. | 충분한 정보가 있어도 확인·개선을 멈추지 않는지 관찰. |
| [009](gold_ccd_profile_009.json) | 승인·인정 추구 | SNS 반응과 타인의 평가로 자기 가치를 판단함. | 상담자의 확인을 구하는 행동과 자기 관점 형성을 구분. |
| [014](gold_ccd_profile_014.json) | 부정성·비관주의 | 좋은 소식에서도 위험·비용·실패 가능성을 먼저 찾음. | 반대 근거로 해석을 조정하는지 다른 위험을 찾는지 관찰. |
| [016](gold_ccd_profile_016.json) | 사회적 고립·소외 | 관계를 원하면서도 초대를 의례적이라고 해석해 참여를 피함. | 호의의 해석과 참여 방식별 공개·행동 의향을 관찰. |
