# group1 — 서로 다른 대처 방식 관찰

`data/profiles/source`에서 같은 번호의 한국어 프로필을 원문 그대로 복사했습니다. 기존 영어 묶음의 번호와 그룹 구성은 유지했습니다.

아래 trajectory는 프로필의 신념·대처 전략·사건에 근거한 관찰 가설이며 실제 생성 결과로 확인해야 합니다.

| 프로필 | 주요 특성 | 선별 근거 | 관찰할 흐름 |
|---|---|---|---|
| [001](gold_ccd_profile_001.json) | 결함·수치심 | 약점을 드러내면 관계가 끝날 것이라고 생각해 정보를 감추거나 과도하게 사과함. | 화제 전환·경험 축소와 공개 범위의 변화를 관찰. |
| [002](gold_ccd_profile_002.json) | 자기희생 | 타인의 요구를 우선하고 자기 필요를 표현하거나 도움을 요청할 때 죄책감을 느낌. | 겉으로 동의하는 행동과 실제 자기 욕구 표현을 구분. |
| [005](gold_ccd_profile_005.json) | 특권의식·과대성 | 직장 문제를 타인에게 돌리지만 가족 관계의 위기에는 동요함. | 반박·형식적 참여와 주제별 취약성 공개의 차이를 관찰. |
| [007](gold_ccd_profile_007.json) | 위험·질병 취약성 | 정상 검사 결과에도 반복 확인과 활동 회피를 지속함. | 정보 확인 후 재확인하는 흐름과 불확실성 처리를 관찰. |
| [008](gold_ccd_profile_008.json) | 정서적 억제 | 감정 질문에서 일정·절차·해결책으로 화제를 옮김. | 사건 설명과 감정 표현의 차이를 관찰. |
