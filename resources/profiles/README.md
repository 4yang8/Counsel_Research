# 에이전틱 실험용 프로필 묶음

총 3묶음, 각 5개, 중복 없는 15개 프로필입니다. 신념·대처 행동·상담 참여 방식의 차이를 기준으로 선별했습니다.

프로필 JSON은 `data/profiles/source`의 **한국어 원본**을 변경 없이 복사했습니다. 기존 영어 묶음과 같은 번호·그룹 구성을 유지하며, 선별 근거도 해당 한국어 프로필을 기준으로 정리했습니다. 요청에서 언급된 `data/profiles/001~100` 폴더는 현재 저장소에 없어, 같은 번호의 한국어 원본이 있는 `data/profiles/source`를 사용했습니다.

| 폴더 | 프로필 ID | 관찰 목적 |
|---|---|---|
| [group1](group1/README.md) | 001, 002, 005, 007, 008 | 서로 다른 대처 방식 관찰 |
| [group2](group2/README.md) | 006, 010, 011, 012, 018 | 다음 선택을 가로막는 이유 비교 |
| [group3](group3/README.md) | 003, 004, 009, 014, 016 | 평가와 긍정적 정보의 해석 비교 |

각 그룹의 README에 프로필별 선별 근거와 예상 관찰 흐름을 정리했습니다. 이 파일들은 실험 입력 후보이며 실제 trajectory 차이가 검증된 결과는 아닙니다.

기본/에이전틱 버전을 비교할 때는 같은 프로필의 초기 상태·기질·상담자 조건을 맞추세요. 조회 행동을 비교하려면 초기 제공 정보와 도구로 조회할 정보를 별도로 설계해야 합니다. 기존 실행 스크립트는 이 폴더를 자동으로 사용하도록 변경하지 않았습니다.

## 신뢰 대조 실습

기존 011 원본과 같은 형식·주요 사건을 유지하면서 신뢰에 대한 해석·정서·대처를 다르게 작성한 [대조 프로필](trust_contrast/README.md)을 추가했습니다. 상담 실습 UI의 실험 프로필에서 원본과 대조를 선택할 수 있습니다.
