# 신뢰 대조 프로필

- 원본: `../group2/gold_ccd_profile_011.json` (`gold_011`). 수정하지 않았다.
- 대조: `profile_011_open.json` (`trust_011_open`). 가상으로 작성한 실습 자료다.

대조 프로필은 원본과 JSON 필드 구조, 나이·직업·생활 배경, 성장기의 구체적 사건, 네 가지 상황의 발생 사건을 유지한다. 타인의 의도를 일반적으로 의심하는 원본과 달리, 설명·경계 존중·행동의 일관성을 경험하면 신뢰를 회복할 수 있도록 신념, 사건의 현재 의미, 감정과 대처를 함께 수정했다. 최근 사건으로 인한 긴장과 상처는 남아 있으므로 즉시 모든 사람을 믿는 설정이 아니다.

`young_domain` / `young_schema`는 호환성을 위해 같은 필드를 사용했으며 대조 설정의 표기는 공식 Young 스키마명이나 임상 판정이 아니다. 개인정보·주요 사건은 맞췄지만 여러 신념·감정·대처를 함께 조작한 대조이므로 신뢰 변수 하나만의 인과효과를 분리하는 실험은 아니다.

UI의 실험 프로필에서 `011 · 불신 중심 (원본)`과 `011 대조 · 신뢰 회복에 열린 편`을 선택한다. 두 조건의 기본 대화는 모두 비어 있고, 같은 상담 시작 문장을 사용한다. `프로필 원본` 탭에서는 두 파일 전체를 조회할 수 있다.
